# 动态规划

## 一、DP通用解法四步骤

所有动态规划题目遵循 **固定四步求解流程** ，核心顺序不可颠倒： **确定DP数组含义 → 确定递推公式 → 确定初始化 → 确定遍历顺序** ，所有DP题型均基于该流程演变。

### 1. 确定DP数组的含义

dp[i] 或 dp[i][j] 代表什么。

核心问题：是"前i个"还是"第i个"？开多大的数组？一维还是二维？

**为什么要开 n+1？** 因为要返回 `dp[n]`，下标从 0 到 n，一共 n+1 个位置。开 n 的话只能到 `dp[n-1]`，不够用。

### 2. 确定递推公式

dp[i] 如何由前面的子问题推出，即**状态转移方程**。

### 3. 确定如何初始化

dp 数组的初始值（边界条件），即递推公式的起点。

### 4. 确定遍历顺序

按什么顺序填表：从前往后还是从后往前？维度间怎么遍历？

> **关键：确定遍历顺序之前必须先确定初始化，否则无法填表。**

## 二、DP本质：从子问题推导当前问题

和回溯的本质对比：

|              | 回溯                       | 动态规划                         |
| ------------ | -------------------------- | -------------------------------- |
| **本质**     | 递归模拟 n 层 for 循环     | 从子问题推导当前问题             |
| **方向**     | 深度优先，一路走到黑再回头 | 填表，从小问题开始逐步推大问题   |
| **核心操作** | 做选择 → 递归 → 撤销选择   | 填 dp 表，dp[i] 由前面的状态推出 |

## 三、背包问题的两种子题型（极其重要）

同样是背包问题，**求最大价值**和**求方案数**的递推公式完全不同：

|              | 求最大价值                              | 求方案数                                               |
| ------------ | --------------------------------------- | ------------------------------------------------------ |
| **问题**     | 装满容量为 j 的背包，最多能装多少？     | 装满容量为 j 的背包，有多少种方法？                    |
| **递推公式** | `dp[j] = max(dp[j], dp[j-w[i]] + v[i])` | `dp[j] += dp[j - w[i]]`                                |
| **初始化**   | 全 0（什么都没选，价值为 0）            | `dp[0] = 1`，其余为 0（凑出 0 有一种方案：什么都不选） |
| **为什么**   | 选或不选，取**较大值** → 用 `max`       | 选或不选都能到达，方案数**相加** → 用 `+=`             |
| **典型题目** | 416、1049、carl46                       | 494（目标和）                                          |

**适用范围**：这个区分在 0/1 背包和完全背包中都成立，区别只在于内层循环方向（倒序 vs 正序）。

**一句话记忆**：取最大用 `max`，数方案用 `+=`。

## 四、DP 数组的两种定义（极其重要）

dp 数组的定义直接决定递推公式怎么写。两种定义适用于不同场景：

### 定义 A：以 i 结尾

`dp[i]` = 以 nums[i] 结尾的最优解（**强制包含 nums[i]**）

```
不匹配时：dp[i] = 1 或 0（重新开始，不能继承前面的结果）
答案：max(dp)（最长不一定在最后一个位置）
```

**什么时候用**：
- **有单调性约束**：LIS 要求 nums[j] < nums[i]，不能随便继承前面的结果
- **必须连续**：子数组断了就重新开始，dp[i] = 0
- **不能继承**：当前元素不满足条件时，前面的结果没法直接拿来用

```cpp
// 300 LIS：nums[j] < nums[i] 才能接，否则 dp[i] = 1
dp[i] = max(dp[i], dp[j] + 1);  // j < i, nums[j] < nums[i]

// 718 子数组：不匹配就断了，dp[i][j] = 0
dp[i][j] = dp[i-1][j-1] + 1;    // 匹配时
```

### 定义 B：前 i 个

`dp[i]` = 用前 i 个元素的最优解（**不一定包含 nums[i]**）

```
不匹配时：dp[i] = max(dp[i-1][j], dp[i][j-1])（继承前面的结果）
答案：dp[n]（最后一个格子就是最终答案）
```

**什么时候用**：
- **能继承前面的结果**：不匹配时可以跳过当前元素，保留之前的结果
- **不要求连续**：子序列可以跳过，背包可以不选
- **递推公式简洁**：只依赖相邻状态，O(1) 转移

```cpp
// 1143 LCS：不匹配时跳过一个，继承之前的结果
dp[i][j] = max(dp[i-1][j], dp[i][j-1]);  // 不匹配
dp[i][j] = dp[i-1][j-1] + 1;             // 匹配

// 背包：不选当前物品，dp[j] 保持不变（继承上一轮）
dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
```

### 对比总结

| | 定义 A：以 i 结尾 | 定义 B：前 i 个 |
|---|---|---|
| **不匹配时** | dp[i] = 0 或 1（重新开始） | dp[i] = max(继承前面) |
| **答案位置** | max(dp) | dp[n] 或 dp[m][n] |
| **典型题目** | 300（LIS）、674、718 | 背包、1143（LCS）、139 |
| **递推依赖** | 所有 j < i（可能 O(n²)） | 相邻状态（O(1) 转移） |

**一句话判断**：不匹配时能不能继承前面的结果？
- **能** → 用"前 i 个"（定义 B）
- **不能** → 用"以 i 结尾"（定义 A）

**为什么 LIS 必须"以 i 结尾"，LCS 可以"前 i 个"？**

两者都是子序列问题，但约束条件不同：

- **LIS（递增约束）**：nums[i] 比当前最长子序列的尾数小，但你不能确定它比其他没那么长的子序列的尾数大还是小。比如当前最长是 [2,5,7]（尾数7），来了个 4，4 < 7 不能接在 [2,5,7] 后面，但 4 > 3，可以接在 [2,3] 后面变成 [2,3,4]。你不知道 4 能接在哪个后面，**必须遍历所有 j**。

- **LCS（相等约束）**：只需要判断 text1[i] == text2[j]，没有大小比较。不匹配时直接跳过（继承 dp[i-1][j] 或 dp[i][j-1]），**不需要遍历所有 j**。

```cpp
// LIS：有单调性，不能随便继承，要遍历所有 j
if (nums[j] < nums[i])
    dp[i] = max(dp[i], dp[j] + 1);  // 必须逐个比较

// LCS：只判断相等，不匹配就跳过
if (text1[i] != text2[j])
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);  // 直接继承
```

## 五、核心题型分类

### 题型一：斐波那契型（递推只依赖前几个状态）

**特征**：dp[i] 只依赖前面常数个状态，递推公式是固定模式。

```cpp
// 爬楼梯、斐波那契
dp[i] = dp[i-1] + dp[i-2]

// 最小花费爬楼梯（746）
dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
// 初始化：dp[0] = dp[1] = 0（题目说可以从第0或第1阶开始，免费）

// 整数拆分（343）
dp[i] = max(j*(i-j), j*dp[i-j], dp[i])
// j*(i-j): 拆成两个数（i-j 不拆）
// j*dp[i-j]: 拆成两个以上（i-j 继续拆）
// dp[i]: 之前 j 循环积累的最大值

// 递推公式的本质：对每个 j，比较 (i-j) 到底拆不拆？
// 循环范围：j 从 2 到 i-2（不访问 dp[1]，避免未定义 + 对称性去重）
```

**典型题目**：509、70、746、343

---

### 题型二：二维网格路径（只能向右或向下）

**特征**：二维 dp 数组，每个格子只能从上方或左方转移过来。

```cpp
dp[i][j] = dp[i-1][j] + dp[i][j-1]  // 无障碍
// 有障碍时，障碍格 dp[i][j] = 0
```

**初始化**：第一行和第一列只能从一个方向到达（全 1 或根据障碍设置）。

**62 vs 63 对比：**

|                   | 62（无障碍）              | 63（有障碍）                            |
| ----------------- | ------------------------- | --------------------------------------- |
| **dp 初始化**     | 全开 0，第一行/列设为 1   | 全开 0，第一行/列设为 1（遇到障碍停止） |
| **递推执行条件**  | 无条件执行                | 只在 `obstacleGrid[i][j]==0` 时执行     |
| **起点/终点检查** | 不需要                    | 起点或终点是障碍直接 return 0           |
| **返回值**        | `dp[m][n]`（开 m+1 数组） | `dp[m-1][n-1]`（开 m×n 数组）           |

**63 题关键点：**

- 初始化第一行/列时，遇到障碍必须 **break**，后面所有格子保持 0（被挡住了，不可能到达）
- 递推时障碍格不处理，保持原始值 0

**典型题目**：62（不同路径）、63（不同路径II，加障碍）

---

### 题型三：卡特兰数（二叉搜索树计数）

**特征**：以每个节点为根，左右子树独立，结果 = 左子树数量 × 右子树数量，遍历所有根节点求和。

**递推公式**：

```cpp
dp[i] += dp[j-1] * dp[i-j]
// j 从 1 到 i，j 是根节点
// dp[j-1]: 左子树有 j-1 个元素
// dp[i-j]: 右子树有 i-j 个元素
```

**初始化**：`dp[0] = 1`（空树是一种合法的 BST，也是递推公式能运行的必要条件）

**为什么 dp[0] = 1？** 当 j=1 时（1 做根），左子树 0 个元素，结果是 `dp[0] * dp[i-1]`。如果 dp[0]=0，这个根的贡献就是 0，整个结果就错了。

**典型题目**：96（不同的二叉搜索树）

### 题型四：0/1 背包（每个物品只能用一次）

**核心问题**：给定容量和物品，每个物品只能选一次。递推公式见第三章（求最大价值 vs 求方案数）。

#### 二维写法（理解用）

**dp 含义**：`dp[i][j]` = 背包容量为 j，从物品 0~i 中选，最大价值。

**递推公式**：

```cpp
dp[i][j] = max(dp[i-1][j], dp[i-1][j - weight[i]] + value[i])
//             不选第i个        选第i个
```

**初始化**：

```cpp
// dp[i][0] = 0（容量为0，装不了任何东西）
// dp[0][j]：只有物品0，容量j时的价值
for (int j = weight[0]; j <= W; j++)
    dp[0][j] = value[0];
```

**遍历顺序**：先物品还是先背包都可以。因为 `dp[i][j]` 依赖的是正上方 `dp[i-1][j]` 和左上方 `dp[i-1][j-weight[i]]`，不管先遍历哪个方向，这两个位置都已经计算好了。

#### 一维空间优化（实际写法）

**dp 含义**：`dp[j]` = 背包容量为 j 时的最大价值。

**递推公式**：

```cpp
dp[j] = max(dp[j], dp[j - weight[i]] + value[i])
//        不选当前物品   选当前物品
```

**为什么 dp[j] 就是"不选当前物品"？**

因为数组复用空间，`dp[j]` 在被当前物品更新之前，存的是上一轮的结果，也就是二维的 `dp[i-1][j]`。所以不改它就是不选当前物品。

```
第 i 轮开始前：dp[j] = dp[i-1][j]（上一轮的结果）
执行 max(dp[j], dp[j-weight[i]] + value[i])
         ↑               ↑
    dp[i-1][j]     dp[i-1][j-weight[i]] + value[i]
    （不选当前物品）    （选当前物品）
```

**一维和二维的对应关系：**

| 一维              | 二维                   | 含义         |
| ----------------- | ---------------------- | ------------ |
| `dp[j]`（未更新） | `dp[i-1][j]`           | 不选当前物品 |
| `dp[j-weight[i]]` | `dp[i-1][j-weight[i]]` | 选当前物品   |

**为什么 1D 不需要开第二维？**

因为**倒序遍历**自动保证了这一点：计算 `dp[j]` 时，`dp[j]` 和 `dp[j-nums[i]]` 都还没被当前物品更新过，它们天然就是上一层 `dp[i-1]` 的结果。所以 1D 版本不需要显式记录 `i-1`，倒序遍历本身就是 `dp[i-1]` 的替代品。

**遍历顺序（关键）**：**必须先物品，再倒序遍历背包**

```cpp
for (int i = 0; i < n; i++)                    // 外层：物品
    for (int j = target; j >= weight[i]; j--)  // 内层：背包，倒序！
        dp[j] = max(dp[j], dp[j - weight[i]] + value[i]);
```

**为什么必须倒序遍历背包？**

```
正序遍历 j：dp[j] → dp[j-weight[i]] 已经被当前物品更新过了
             → 同一个物品被选了多次 → 这是完全背包的行为

倒序遍历 j：dp[j-weight[i]] 还是上一轮的值（没被当前物品更新）
             → 一个物品只选一次 → 这是 0/1 背包的行为
```

**为什么必须先物品再背包？（不能反过来）**

如果先遍历背包（外层 j 倒序，内层遍历所有物品）：对于每个容量 j，遍历物品 i 时 `dp[j-weight[i]]` 还没被更新（j 从大到小走，j-weight[i] < j 还没处理到），所以 `dp[j-weight[i]] = 0`。结果是**只能选一个物品**，不可能组合多个物品，不符合 0/1 背包的逻辑。

**典型题目**：carl46（背包基础）、416（分割等和子集）、1049（最后一块石头的重量II）、494（目标和）、474（一和零，二维约束）

### 题型五：完全背包（每个物品可用无限次）

#### 二维写法

**dp 含义**：`dp[i][j]` = 从物品 0~i 中选，容量为 j 的最大价值（和 0/1 背包一样）。

**递推公式**：

```cpp
dp[i][j] = max(dp[i-1][j], dp[i][j - weight[i]] + value[i])
//             不选第i个        选第i个（注意是 dp[i] 不是 dp[i-1]）
```

**和 0/1 背包的区别**：选当前物品时用 `dp[i][j-weight[i]]`（当前行）而不是 `dp[i-1][j-weight[i]]`（上一行），因为完全背包允许重复选当前物品。

**初始化**：`dp[i][0] = 0`；`dp[0][j]` 需要考虑物品 0 可以被多次选取：

```cpp
for (int j = weight[0]; j <= W; j++)
    dp[0][j] = dp[0][j - weight[0]] + value[0];  // 物品0可以重复选
```

**遍历顺序**：都可以（先物品再背包，或先背包再物品），因为正序遍历保证左边和上面都已更新。

#### 一维空间优化（实际写法）

**递推公式**：

```cpp
dp[j] = max(dp[j], dp[j - weight[i]] + value[i])
//        不选当前物品   选当前物品
```

**和 0/1 背包的唯一区别：正序遍历**。

**为什么正序？**

```
倒序（0/1 背包）：dp[j-weight[i]] 还没被更新 → 是上一层的值 → 只能选一次
正序（完全背包）：dp[j-weight[i]] 已经被当前物品更新过了 → 可以重复选
```

正序遍历时，先更新小的 j，再更新大的 j。处理 `dp[j]` 时，`dp[j-weight[i]]` 已经是当前轮更新过的值，里面已经包含了"选当前物品"的结果，所以可以继续叠加 → 一个物品被选了多次。

**遍历顺序（关键区分）**：都是正序，但**先物品还是先背包决定了是组合还是排列**。

| 遍历顺序           | 结果                   | 原因                                                |
| ------------------ | ---------------------- | --------------------------------------------------- |
| **先物品，再背包** | **组合数**（顺序无关） | 物品按固定顺序出现，{1,2} 和 {2,1} 只算一次         |
| **先背包，再物品** | **排列数**（顺序有关） | 同一组物品可以按不同顺序出现，{1,2} 和 {2,1} 算两次 |

**为什么？** 画出二维 DP 表来看：

- 先物品再背包：一行一行填，物品顺序固定（1 永远在 2 前面）→ 组合
- 先背包再物品：一列一列填，后面出现的物品可以和前面的混合排列 → 排列

**编码细节**：

```cpp
// 先物品再背包：j 从 coins[i] 开始，不需要 if 判断
for (int i = 0; i < n; i++)
    for (int j = coins[i]; j <= amount; j++)

// 先背包再物品：j 从 1 开始，需要 if 判断容量是否够
for (int j = 1; j <= amount; j++)
    for (int i = 0; i < n; i++)
        if (j >= coins[i])  // 容量够才能用这个物品
```

#### leetcode 518. 零钱兑换II（完全背包求方案数，组合数）

**问题**：给定硬币数组 coins 和金额 amount，求凑出 amount 的方案数（每种硬币可用无限次）。

**四步骤**：

1. **dp 含义**：`dp[j]` = 凑出金额 j 的方案数
2. **递推公式**：`dp[j] += dp[j - coins[i]]`（不选 + 选当前硬币）
3. **初始化**：`dp[0] = 1`（凑出金额 0 有一种方案：什么都不选）
4. **遍历顺序**：**先物品，再正序遍历背包**（求组合数）

```cpp
for (int i = 0; i < n; i++)                    // 先物品
    for (int j = coins[i]; j <= amount; j++)   // 正序遍历背包
        dp[j] += dp[j - coins[i]];
```

#### leetcode 377. 组合总和IV（完全背包求排列数）

和 518 完全一样，唯一区别：**先背包，再物品**（求排列数）。

```cpp
for (int j = 1; j <= target; j++)              // 先背包
    for (int i = 0; i < n; i++)                // 再物品
        if (j >= nums[i]) dp[j] += dp[j - nums[i]];
```

**518 vs 377 对比**：

|              | 518（零钱兑换II）         | 377（组合总和IV）        |
| ------------ | ------------------------- | ------------------------ |
| **求什么**   | 组合数                    | 排列数                   |
| **遍历顺序** | 先物品，再背包            | **先背包，再物品**       |
| **递推公式** | `dp[j] += dp[j-coins[i]]` | `dp[j] += dp[j-nums[i]]` |
| **其他**     | 完全一样                  | 完全一样                 |

#### leetcode 322. 零钱兑换（完全背包，求最小值）

和前面求方案数的区别：**求最小值，不是求方案数**。

**两个关键点**：

1. **初始化为 INT_MAX**：求最小值，一开始假设所有金额都凑不出（INT_MAX），能凑出就被更小的值更新
2. **递推公式前要判断子问题是否有解**：

```cpp
dp[j] = min(dp[j], dp[j - coins[i]] + 1);
// 但前提是 dp[j - coins[i]] != INT_MAX
// 如果 dp[j-coins[i]] 还是 INT_MAX，说明这个子问题无解
// 没必要 +1，因为无解 + 1 还是无解
```

```cpp
// 完整写法
for (int i = 0; i < n; i++)
    for (int j = coins[i]; j <= amount; j++)
        if (dp[j - coins[i]] != INT_MAX)  // 子问题有解才更新
            dp[j] = min(dp[j], dp[j - coins[i]] + 1);
```

#### leetcode 139. 单词拆分（完全背包，物品从字符串截取）

**问题**：给定字符串 s 和单词表 wordDict，判断 s 能否被拆分为 wordDict 中的单词。

**核心区别**：之前的背包题物品是给定的数组，这道题的"物品"是从字符串中**截取的子串**，需要遍历所有截取位置然后去 wordDict 里查。

**四步骤**：

1. **dp 含义**：`dp[i]` = 长度为 i 的子串 `s[0:i]` 能否被拆分
2. **递推公式**：`dp[i] = dp[j] && s[j:i] 在 wordDict 中`（j 从 0 到 i-1）
3. **初始化**：`dp[0] = true`（空串可以被拆分，也是递推能运行的起点）
4. **遍历顺序**：先遍历背包（i 从 1 到 s.length），再遍历截取位置 j

```cpp
dp[0] = true;
for (int i = 1; i <= s.length(); i++)        // 背包：字符串长度
    for (int j = 0; j < i; j++)              // 截取位置
        if (dp[j] && wordDict.count(s.substr(j, i - j)))
            dp[i] = true;
```

**和标准完全背包的对比**：

|                  | 标准完全背包     | 139（单词拆分）                    |
| ---------------- | ---------------- | ---------------------------------- |
| **物品来源**     | 给定的数组       | 从字符串截取的子串                 |
| **遍历物品**     | 遍历数组下标     | 遍历截取位置 j                     |
| **判断是否可选** | `j >= weight[i]` | `wordDict.count(s.substr(j, i-j))` |
| **本质**         | 完全背包         | **完全背包（物品动态生成）**       |

### 题型六：子集/子序列问题（转化为背包）

**特征**：从数组中选取子集满足某种条件，本质是 0/1 背包的变体。

#### 核心转化：求最大价值 → 能不能装满

当 `value[i] = weight[i]`（每个数的价值等于它的重量）时：

- `dp[j]` = 背包容量为 j 时，能装的最大价值
- 因为价值不可能超过重量，所以 `dp[target]` 最大就是 target
- **`dp[target] == target` → 背包装满了 → 找到了一个子集和为 target → 可以等分**

这就是把"求最大价值"转化为"能不能装满"的关键。

#### leetcode 416. 分割等和子集

**转化**：数组能否分成两个等和子集 → 背包容量为 sum/2，每个数的 weight = value = nums[i]，能不能装满

**四步骤：**

1. **dp 含义**：`dp[j]` = 背包容量为 j 时能装的最大价值
2. **递推公式**：`dp[j] = max(dp[j], dp[j - nums[i]] + nums[i])`（标准 0/1 背包）
3. **初始化**：全 0
4. **遍历顺序**：先物品，再倒序遍历背包

**判断条件**：`dp[target] == target` → true，否则 false

**注意**：sum 为奇数直接返回 false（不可能等分）

#### 其他类似题目

#### leetcode 494. 目标和（求方案数，构造思路极其巧妙）

**问题**：给数组 nums 和目标值 tar

get，每个数前面可以加 `+` 或 `-`，求有多少种方式使结果等于 target。

**构造思路（核心）**：

只研究 left 组（加号组），left 满足条件 right 自然满足：

```
left + right = sum      （所有数的总和）
left - right = target   （加号组 - 减号组 = 目标值）
→ left = (sum + target) / 2
```

**转化**：从 nums 中选若干个数，有多少种方式凑出 `left = (sum + target) / 2`？这就是 **0/1 背包求方案数**。

**前提检查**：`sum + target` 必须是偶数；`abs(target) > sum` 直接返回 0。

**四步骤**：

1. **dp 含义**：`dp[j]` = 凑出容量 j 的方案数
2. **递推公式**：`dp[j] += dp[j - nums[i]]`（不选当前物品 + 选当前物品）
3. **初始化**：`dp[0] = 1`（凑出 0 有一种方案：什么都不选）
4. **遍历顺序**：先物品（从 0 开始），再**倒序**遍历容量

**0 的处理（2^n）**：

当 `nums[i]=0` 时，`dp[j] += dp[j-0]` 即 `dp[j] += dp[j]`，方案数自动翻倍。

本质：0 放 left 组或 right 组，left 值不变，但确实是两种不同选择，所以方法数 ×2。有 n 个 0 就是 2^n。从第 0 个物品开始遍历，遇到 0 自然翻倍，不需要额外处理。

**一维中 dp[j] 的含义（极其重要）**：

`dp[j]` **永远代表 `dp[i-1][j]`**（上一轮的结果），因为外层遍历物品、内层倒序遍历容量，计算 `dp[j]` 时它还没被当前物品更新过。

```
dp[j]（未更新）  = dp[i-1][j]        → 不选当前物品
dp[j-nums[i]]    = dp[i-1][j-nums[i]] → 选当前物品
```

**典型题目**：494（目标和）

#### leetcode 474. 一和零（重量有两个维度的 0/1 背包）

**问题**：给定二进制字符串数组 strs，和整数 m（0 的上限）、n（1 的上限），找出最大子集大小，使得子集中最多有 m 个 0 和 n 个 1。

**核心理解：它还是 0/1 背包，只是"重量"有两个维度**。

`dp[i][j]` 不是二维背包，而是一维背包的重量用两个维度表示：

- `dp[i][j]` = 最多用 i 个 0 和 j 个 1，能装的最大子集大小

**四步骤**：

1. **dp 含义**：`dp[i][j]` = 最多 i 个 0、j 个 1 能装的最大子集大小
2. **递推公式**：`dp[i][j] = max(dp[i][j], dp[i - zeros][j - ones] + 1)`（标准 0/1 背包，只是减的是两个维度）
3. **初始化**：全部为 0
4. **遍历顺序**：先物品，再倒序遍历两个维度（i 从 m 到 zeros，j 从 n 到 ones）

**和标准 0/1 背包的对比**：

|              | 标准 0/1 背包                   | 474（一和零）                              |
| ------------ | ------------------------------- | ------------------------------------------ |
| **重量维度** | 1 个（容量 j）                  | 2 个（0 的个数 i，1 的个数 j）             |
| **递推**     | `dp[j] = max(dp[j], dp[j-w]+v)` | `dp[i][j] = max(dp[i][j], dp[i-z][j-o]+1)` |
| **本质**     | 一维背包                        | **一维背包，重量有两个维度**               |

**典型题目**：474（一和零）

#### leetcode 718. 最长重复子数组（两个数组的公共子数组）

**问题**：给定两个数组 nums1 和 nums2，找到两个数组中公共的、长度最长的子数组。

**核心**：两个集合的公共部分 → dp 数组必须**二维**（两个变量控制）。

**四步骤**：
1. **dp 含义**：`dp[i][j]` = 以 nums1[i] 和 nums2[j] 结尾的最长公共子数组长度（**必须以这两个元素结尾**）
2. **递推公式**：
```cpp
if (nums1[i] == nums2[j] && i > 0 && j > 0)
    dp[i][j] = dp[i-1][j-1] + 1;
// 不相等时 dp[i][j] = 0（连续子数组，断了就是 0）
```
3. **初始化**：第一行和第一列要逐个检查相等才设 1（不是全 0）
```cpp
for (int j = 0; j < n; j++)
    if (nums2[j] == nums1[0]) dp[0][j] = 1;
for (int i = 0; i < m; i++)
    if (nums1[i] == nums2[0]) dp[i][0] = 1;
```
4. **遍历顺序**：**必须从前往后**（dp[i][j] 依赖 dp[i-1][j-1]，从后往前拿不到这个值）

```cpp
int result = 0;
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++) {
        if (nums1[i] == nums2[j] && i > 0 && j > 0)
            dp[i][j] = dp[i-1][j-1] + 1;
        result = max(result, dp[i][j]);
    }
return result;
```

**为什么需要 result？**

`dp[i][j]` 表示"以 nums1[i] 和 nums2[j] 结尾"的长度，最长的不一定在右下角，可能在中间某个位置，所以要遍历时用 result 记录最大值。

**和 300/674 的共同点**：dp[i][j] 都是"必须以某个东西结尾"，所以需要 result 全局记录最大值。

**偏移 DP 套路（通用技巧）**：

字符串/数组类 DP 中，dp[i][j] 可以偏移一位：让 dp[i][j] 表示"以 text1[i-1] 和 text2[j-1] 结尾"，而不是 text1[i] 和 text2[j]。

好处：dp[0][j] 和 dp[i][0] 代表空串，天然全 0，**不需要单独初始化第一行/列**。

```cpp
// 不偏移：dp[i][j] 以 text1[i], text2[j] 结尾，第一行/列需要单独初始化
// 偏移：  dp[i][j] 以 text1[i-1], text2[j-1] 结尾，第一行/列全是 0

// 718 偏移写法
vector<vector<int>> dp(m+1, vector<int>(n+1, 0));  // 开 m+1, n+1
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        if (nums1[i-1] == nums2[j-2])  // 注意是 i-1, j-1
            dp[i][j] = dp[i-1][j-1] + 1;
```

#### leetcode 1143. 最长公共子序列（LCS，不要求连续）

**问题**：给定两个字符串 text1 和 text2，求最长公共子序列长度（不要求连续）。

**和 718 的关键区别**：

| | 718（子数组，连续） | 1143（子序列，不连续） |
|---|---|---|
| **不相等时** | `dp[i][j] = 0`（断了重新开始） | `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（跳过，保留之前的结果） |
| **原因** | 子数组必须连续，不匹配就断了 | 子序列不要求连续，不匹配可以跳过 |

**四步骤**：
1. **dp 含义**：`dp[i][j]` = text1[0..i] 和 text2[0..j] 的最长公共子序列长度
2. **递推公式**：
```cpp
if (text1[i] == text2[j])
    dp[i][j] = dp[i-1][j-1] + 1;  // 匹配，接上前面
else
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]);  // 不匹配，跳过一个
```
3. **初始化**：全部为 0
4. **遍历顺序**：必须从前往后（依赖 dp[i-1][j-1]）

```cpp
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++) {
        if (text1[i] == text2[j])
            dp[i][j] = (i > 0 && j > 0) ? dp[i-1][j-1] + 1 : 1;
        else {
            int up = (i > 0) ? dp[i-1][j] : 0;
            int left = (j > 0) ? dp[i][j-1] : 0;
            dp[i][j] = max(up, left);
        }
    }
return dp[m-1][n-1];
```

### 编辑距离系列（dp 值直接代表操作，不需要模拟）

**核心思想**：dp[i][j] 的值本身就代表操作次数，不需要真正去模拟删除、插入、替换。通过 `dp[i-1][j]`、`dp[i][j-1]`、`dp[i-1][j-1]` 这些状态转移，自然就包含了操作的含义。

**公共基础**：
- 都用**偏移 DP**（两个字符串操作的标准套路）
- `dp[i][j]` 代表 word1 的前 i 个字符和 word2 的前 j 个字符的某种关系
- 正序遍历，保证顺序

**"删除/跳过"的本质**：不是真的删字符，是**指针往前移**——当前字符匹配不上，跳过它，看下一个。

**谁匹配谁（重要）**：
- **s 中找 t**（如 11）：t 是目标，只能跳过 s（`dp[i-1][j]`）
- **s 和 t 地位平等**（如 1143、583、72）：两边都可以跳

#### leetcode 72. 编辑距离（删除/增加/替换，三种操作）

**问题**：将 word1 转换成 word2 所需的最少操作数。

**递推公式**：
```cpp
if (word1[i-1] == word2[j-1])
    dp[i][j] = dp[i-1][j-1];  // 匹配，不需要操作
else
    dp[i][j] = min({
        dp[i-1][j] + 1,      // 删除 word1 的当前字符
        dp[i][j-1] + 1,      // 插入（= 删除 word2 的字符，可逆操作）
        dp[i-1][j-1] + 1     // 替换
    });
```

**三个操作的本质**：
- **删除**：`dp[i-1][j] + 1`，跳过 word1 的当前字符
- **插入**：`dp[i][j-1] + 1`，跳过 word2 的当前字符（删除和插入是**可逆操作**，效果相同）
- **替换**：`dp[i-1][j-1] + 1`，替换后相等，直接看前面

**核心洞察**：不需要模拟具体操作，dp 值本身就是答案。dp[i][j] 只关心"多少次操作能让前 i 个变成前 j 个"，不关心具体怎么操作。

### 题型七：最长递增子序列（LIS）

**特征**：不要求连续，但要保持相对顺序，求最长的严格递增子序列。

#### leetcode 300. 最长递增子序列

**四步骤**：

1. **dp 含义**：`dp[i]` = 以 `nums[i]` 结尾的最长递增子序列长度（**必须包含 nums[i]**，不能跳过。因为递推公式比较的是尾数，尾数不在序列里，比较就没有意义）
2. **递推公式**：`dp[i] = max(dp[i], dp[j] + 1)`，其中 `j < i` 且 `nums[j] < nums[i]`
3. **初始化**：全部为 1（每个元素本身就是一个长度为 1 的子序列）
4. **遍历顺序**：i 从 1 到 n-1，j 从 0 到 i-1（j 的顺序无所谓）

```cpp
vector<int> dp(n, 1);
for (int i = 1; i < n; i++)
    for (int j = 0; j < i; j++)
        if (nums[j] < nums[i])
            dp[i] = max(dp[i], dp[j] + 1);
return *max_element(dp.begin(), dp.end());
// 注意：答案是 max(dp)，不是 dp[n-1]
// 因为最长子序列不一定以最后一个元素结尾
```

**为什么 j 的顺序无所谓？**

dp[i] 依赖的是"所有 j < i 且 nums[j] < nums[i] 的 dp[j]"，dp[j] 之间没有依赖关系（不像背包的容量有大小关系），所以 j 从前往后或从后往前都可以。

**和背包问题的区别**：

|                | 背包问题                 | LIS                                 |
| -------------- | ------------------------ | ----------------------------------- |
| **dp[j] 依赖** | 特定的 `dp[j-weight[i]]` | **所有** `j < i` 且满足条件的 dp[j] |
| **遍历 j**     | 有固定方向（倒序/正序）  | **顺序无所谓**                      |
| **本质**       | 容量约束下的选择         | 位置约束下的选择                    |

#### leetcode 674. 最长连续递增子序列

和 300 的唯一区别：**连续**，只需要和前一个比，不需要遍历所有 j。

**递推公式**：

```cpp
if (nums[i] > nums[i-1])
    dp[i] = dp[i-1] + 1;  // 接在前一个后面
else
    dp[i] = 1;             // 断了，重新开始
```

**300 vs 674 对比**：

|              | 300（LIS）     | 674（连续LIS）     |
| ------------ | -------------- | ------------------ |
| **是否连续** | 不连续，可跳过 | **连续，不可跳过** |
| **比较范围** | 所有 j < i     | **只和 i-1 比**    |
| **循环**     | 两层 for       | **一层 for**       |
| **返回值**   | max(dp)        | max(dp)            |

**贪心做法**：用一个 count 计数器，连续递增就 +1，断了就重置为 1，更简单。

#### leetcode 53. 最大子数组和（"以 i 结尾"的综合用法）

**问题**：给定整数数组 nums，找到具有最大和的连续子数组（至少包含一个元素），返回其最大和。

**套路应用**：
- 连续 → 必须用"以 i 结尾"定义
- 单个数组 → 不需要偏移 DP
- 以 i 结尾 → 最终用 result 记录全局最大值

**四步骤**：
1. **dp 含义**：`dp[i]` = 以 nums[i] 结尾的最大子数组和
2. **递推公式**：`dp[i] = max(dp[i-1] + nums[i], nums[i])`
   - dp[i-1] + nums[i]：接在前面后面（延续）
   - nums[i]：前面是负数，不如重新开始
3. **初始化**：`dp[0] = nums[0]`，`result = nums[0]`
4. **遍历顺序**：从前往后（依赖 dp[i-1]）

```cpp
vector<int> dp(n);
dp[0] = nums[0];
int result = dp[0];
for (int i = 1; i < n; i++) {
    dp[i] = max(dp[i-1] + nums[i], nums[i]);
    result = max(result, dp[i]);
}
return result;
```

**典型题目**：300（LIS）、674（最长连续递增序列）、53（最大子数组和）

### 题型八：区间 DP

**特征**：dp[i][j] 表示区间 [i, j] 内的某种属性，递推依赖的是**更小的区间** dp[i+1][j-1] 或 dp[i+1][j]、dp[i][j-1]。

**遍历顺序**：区间 DP 的核心是**先算小区间，再算大区间**。因为 dp[i][j] 依赖 dp[i+1][j-1]（左下角），所以：
- i 从下往上（i 从 `n-1` 到 0）
- j 从左往右（j 从 i 到 `n-1`）

**和线性 DP 的区别**：

| | 线性 DP | 区间 DP |
|---|---|---|
| **dp 含义** | dp[i] 或 dp[i][j] 依赖前一个/前一行 | dp[i][j] 依赖更小的区间 |
| **遍历方向** | 从前往后 | i 从下往上，j 从左往右 |
| **典型依赖** | dp[i-1]、dp[i][j-1] | dp[i+1][j-1]、dp[i+1][j] |

#### leetcode 647. 回文子串计数

**问题**：给定字符串 s，统计其中回文子串的数量。

**四步骤**：

1. **dp 含义**：`dp[i][j]` = s[i..j] 这个子串是否是回文串
2. **递推公式**：
```cpp
if (s[i] == s[j]) {
    if (j - i <= 1)       // 单字符 或 两个相邻相同字符
        dp[i][j] = true;
    else                  // 依赖更小区间
        dp[i][j] = dp[i+1][j-1];
}
// s[i] != s[j] 时保持 false（初始化值）
```
3. **初始化**：全部为 false
4. **遍历顺序**：i 从 `n-1` 到 0，j 从 i 到 `n-1`

```cpp
int countSubstrings(string s) {
    int n = s.size();
    vector<vector<bool>> dp(n, vector<bool>(n, false));
    int result = 0;
    for (int i = n - 1; i >= 0; i--) {
        for (int j = i; j < n; j++) {
            if (s[i] == s[j]) {
                if (j - i <= 1 || dp[i + 1][j - 1]) {
                    result++;
                    dp[i][j] = true;
                }
            }
        }
    }
    return result;
}
```

**为什么 i 从下往上？** dp[i][j] 依赖 dp[i+1][j-1]，即 i+1 行的值，所以必须先把下面的行算完。

**典型题目**：647（回文子串）

#### leetcode 516. 最长回文子序列

**问题**：给定字符串 s，找到其中最长的回文子序列长度（不要求连续）。

**和 647 的区别**：647 是子串（连续），516 是子序列（不连续）。

**和编辑距离的联系**：不匹配时 `max(dp[i+1][j], dp[i][j-1])` 本质就是"删掉一个字符看剩下的"，和 583 删除操作的思路完全一样。

**四步骤**：

1. **dp 含义**：`dp[i][j]` = s[i..j] 区间内最长回文子序列长度
2. **递推公式**：
```cpp
if (s[i] == s[j])
    dp[i][j] = dp[i+1][j-1] + 2;       // 首尾匹配，长度+2
else
    dp[i][j] = max(dp[i+1][j], dp[i][j-1]);  // 跳一个，取较大值
```
3. **初始化**：`dp[i][i] = 1`（单字符是长度为 1 的回文子序列）
4. **遍历顺序**：i 从 `n-1` 到 0，j 从 `i+1` 到 `n-1`

```cpp
int longestPalindromeSubseq(string s) {
    int n = s.size();
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int i = 0; i < n; i++) dp[i][i] = 1;  // 单字符

    for (int i = n - 1; i >= 0; i--)
        for (int j = i + 1; j < n; j++) {       // j 从 i+1 开始
            if (s[i] == s[j])
                dp[i][j] = dp[i+1][j-1] + 2;
            else
                dp[i][j] = max(dp[i+1][j], dp[i][j-1]);
        }
    return dp[0][n-1];
}
```

**j 为什么从 i+1 开始？** 因为 j==i 时已经初始化为 1，j 从 i+1 开始跳过对角线，避免访问 dp[i+1][i-1]（越界）。

**和编辑距离系列的对比**：

| | 583 删除操作 | 516 回文子序列 |
|---|---|---|
| **不匹配时** | `min(dp[i-1][j], dp[i][j-1]) + 1` | `max(dp[i+1][j], dp[i][j-1])` |
| **本质** | 删一个，操作数+1 | 跳一个，长度不变 |
| **方向** | i-1, j-1（左上） | i+1, j-1（左下，区间DP） |

**典型题目**：516（最长回文子序列）

## 七、0/1 背包 vs 完全背包：最核心的区别

|                  | 0/1 背包                         | 完全背包                                   |
| ---------------- | -------------------------------- | ------------------------------------------ |
| **物品使用次数** | 每个物品只能用一次               | 每个物品可以用无限次                       |
| **内层循环方向** | **逆序**（从大到小）             | **正序**（从小到大）                       |
| **状态转移**     | `dp[i-1][j-weight[i]]`（上一行） | `dp[i][j-weight[i]]`（当前行，允许重复选） |

**一句话记忆：逆序 = 不重复（0/1），正序 = 可重复（完全）。**

## 八、初始化规则

| 题目类型     | 初始化                | 含义                                       |
| ------------ | --------------------- | ------------------------------------------ |
| **求最大值** | `dp[j] = 0`           | 什么都没选，价值为 0                       |
| **求最小值** | `dp[j] = INT_MAX`     | 一开始假设无法凑出，能凑出就被更小的值更新 |
| **求方案数** | `dp[0] = 1`，其余为 0 | 凑出金额 0 有一种方案（什么都不选）        |

## 九、常用技巧汇总

### 1. 偏移 DP

dp[i][j] 表示 text1[i-1] 和 text2[j-1] 结尾（偏移一位），第一行/列代表空串，天然全 0，**不需要单独初始化**。

```cpp
vector<vector<int>> dp(m+1, vector<int>(n+1, 0));  // 开 m+1, n+1
for (int i = 1; i <= m; i++)
    for (int j = 1; j <= n; j++)
        if (text1[i-1] == text2[j-1])  // 注意是 i-1, j-1
            dp[i][j] = dp[i-1][j-1] + 1;
```

适用：**两个或多个字符串**之间的操作（718、1143 等），单个字符串不需要偏移

### 2. result 全局记录最大值

当 dp[i] 的含义是"以 i 结尾"时，最长的不一定在最后一个位置，需要遍历时用 result 记录全局最大值。

```cpp
int result = 0;
for (int i = 0; i < n; i++) {
    // ... 更新 dp[i]
    result = max(result, dp[i]);
}
return result;  // 不是 dp[n-1]
```

适用：300（LIS）、674、718

### 3. 2^n 自动翻倍

当 nums[i]=0 时，`dp[j] += dp[j-0]` 即 `dp[j] += dp[j]`，方案数自动翻倍。0 有 n 个就是 2^n。从第 0 个物品开始遍历，遇到 0 自然翻倍，不需要额外处理。

适用：494（目标和）

### 4. 1D 背包中 dp[j] = dp[i-1][j]

一维 0/1 背包中，`dp[j]` 永远代表上一轮的结果。倒序遍历自动保证：计算 dp[j] 时，dp[j] 和 dp[j-nums[i]] 都没被当前物品更新过。所以 1D 不需要开第二维。

```cpp
dp[j]（未更新）  = dp[i-1][j]        → 不选当前物品
dp[j-nums[i]]    = dp[i-1][j-nums[i]] → 选当前物品
```

适用：所有 0/1 背包一维写法

### 5. 子问题无解判断

求最小值时，初始化为 INT_MAX。递推前要判断子问题是否有解，无解 + 1 还是无解，没必要更新。

```cpp
if (dp[j - coins[i]] != INT_MAX)  // 子问题有解才更新
    dp[j] = min(dp[j], dp[j - coins[i]] + 1);
```

适用：322（零钱兑换）

### 6. 组合数 vs 排列数遍历顺序

完全背包中，遍历顺序决定是组合还是排列：

| 遍历顺序 | 结果 | 原因 |
|---|---|---|
| 先物品，再背包 | **组合数** | 物品顺序固定 |
| 先背包，再物品 | **排列数** | 物品可混合排列 |

编码区别：先物品再背包时 j 从 coins[i] 开始；先背包再物品时 j 从 1 开始，需要 `if (j >= coins[i])` 判断。

适用：518（组合数）、377（排列数）

### 7. 求最大值 vs 求方案数

同样是背包问题，递推公式完全不同：

| | 求最大价值 | 求方案数 |
|---|---|---|
| **递推** | `dp[j] = max(dp[j], dp[j-w]+v)` | `dp[j] += dp[j-w]` |
| **初始化** | 全 0 | `dp[0] = 1` |

一句话：取最大用 `max`，数方案用 `+=`。

## 十、易错点

1. **DP四步骤必须完整**：确定DP数组含义→递推公式→初始化→遍历顺序，缺一不可
2. **状态定义不清**：dp[i][j]的含义必须明确，是"前i个"还是"第i个"
3. **边界条件遗漏**：dp[0][j]和dp[i][0]需要单独处理
4. **遍历顺序错误**：bottom-up需要先计算子问题；0/1背包空间优化时需要逆序遍历
5. **混淆0/1背包和完全背包**：完全背包用dp[i][j-w[i]]而非dp[i-1][j-w[i]]
6. **数组开小了**：要返回 dp[n] 就必须开 n+1 大小，否则越界
