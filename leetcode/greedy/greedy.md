# 贪心算法

## 一、贪心算法的本质

贪心算法的核心是**每一步都做出当前看起来最优的选择**，尝试用局部最优推导全局最优。

**关键区别：贪心 vs 动态规划**

- **贪心**：不能严格证明一定是全局最优。只能先设计一个贪心策略，尝试后验证结果是否正确。适用于题目本身具有贪心性质的情况（如排序后局部最优就是全局最优）。
- **动态规划**：可以严格推导出全局最优解，通过状态转移方程枚举所有子问题。

## 二、题目笔记

### leetcode 455. 分发饼干

**题目**：每个小孩有一个胃口值 g[i]，每块饼干有一个大小 s[j]。一块饼干最多只能满足一个小孩，求最多能满足几个小孩。

**贪心策略**：大饼干优先满足大胃口的小孩。

**为什么这样贪心？**
- 排序后，胃口大的小孩最挑剔，大饼干都满足不了他，小饼干更不可能
- 所以从大胃口的小孩开始处理，用当前最大的饼干去尝试满足
- 如果能满足，就用掉这块饼干（index--），小孩数量 +1
- 如果满足不了，说明当前饼干太小，换下一个更大的饼干（但已经是最大的了，所以这个小孩就放弃）

**遍历顺序**：两个数组都排序，从后往前遍历（从大到小）

```
g = [1, 2, 3]  (排序后)
s = [1, 1, 2]  (排序后)

i = 2 (胃口3): s[2]=2 < 3, 不满足, 跳过
i = 1 (胃口2): s[2]=2 >= 2, 满足! index--, result++
i = 0 (胃口1): s[1]=1 >= 1, 满足! index--, result++

result = 2
```

**代码：**

```cpp
sort(g.begin(), g.end());
sort(s.begin(), s.end());

int index = s.size() - 1;  // 饼干从最大的开始
int result = 0;

for (int i = g.size() - 1; i >= 0; i--) {  // 小孩从胃口最大的开始
    if (index >= 0 && s[index] >= g[i]) {
        index--;    // 用掉这块饼干
        result++;   // 满足一个小孩
    }
    // 不满足就跳过这个小孩（大饼干都满足不了，小饼干更不行）
}
```
