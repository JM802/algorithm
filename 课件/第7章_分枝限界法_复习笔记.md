# 第7章 分枝限界法（Branch-and-Bound）期末复习笔记

## 一、章节概述

分枝限界法是在解空间树上搜索问题解的算法，类似于回溯法但目标不同：回溯法找所有解，分枝限界法找**一个最优解**。采用**广度优先**策略，通过限界函数剪枝。

---

## 二、核心概念

### 2.1 分枝限界法 vs 回溯法

| 特征 | 回溯法 | 分枝限界法 |
|------|--------|-----------|
| 搜索策略 | 深度优先（DFS） | 广度优先（BFS） |
| 求解目标 | 找所有解/一个解 | 找最优解 |
| 结点处理 | 沿一条路走到底再回溯 | 同时扩展所有活结点 |
| 活结点表 | 隐式（递归栈） | 显式（队列/优先队列） |
| 剪枝函数 | 约束函数+限界函数 | 限界函数为主 |

### 2.2 限界函数设计

**求最大值问题：** 设计上界函数 ub
- 根结点的 ub ≥ 最优解的 ub
- 若 ub(当前结点) < 当前最优值，则剪枝

**求最小值问题：** 设计下界函数 lb
- 根结点的 lb ≤ 最优解的 lb
- 若 lb(当前结点) > 当前最优值，则剪枝

### 2.3 两种活结点表组织方式

#### 队列式分枝限界法（FIFO）
```
1. 根结点入队
2. 队头出队，作为扩展结点
3. 从左到右产生所有孩子，满足约束的入队
4. 重复2-3直到找到解或队列为空
```

#### 优先队列式分枝限界法
```
1. 根结点入优先队列
2. 取优先级最高的结点作为扩展结点
3. 产生所有孩子，计算优先级，满足条件的入队
4. 重复2-3直到找到解或队列为空
```

### 2.4 确定解向量的两种方法

1. **保存路径**：每个结点保存从根到该结点的路径（空间大但简单）
2. **双亲指针**：每个结点保存双亲指针，找到最优解后回溯

## 三、经典问题详解

### 3.1 0/1背包问题

**限界函数设计（求上界）：**
```cpp
void bound(NodeType &e) {
    int i = e.i + 1;
    int sumw = e.w;
    double sumv = e.v;
    while ((sumw + w[i] <= W) && i <= n) {
        sumw += w[i];
        sumv += v[i];
        i++;
    }
    if (i <= n)
        e.ub = sumv + (W - sumw) * v[i] / w[i];  // 部分装入
    else
        e.ub = sumv;  // 全部装入
}
```

**队列式实现核心逻辑：**
```cpp
while (!qu.empty()) {
    e = qu.front(); qu.pop();
    // 左孩子：选物品i
    if (e.w + w[e.i+1] <= W) {
        e1 = e; e1.i++; e1.w += w[e1.i]; e1.v += v[e1.i];
        e1.x[e1.i] = 1;
        bound(e1);
        EnQueue(e1, qu);
    }
    // 右孩子：不选物品i
    e2 = e; e2.i++;
    e2.x[e2.i] = 0;
    bound(e2);
    if (e2.ub > maxv) EnQueue(e2, qu);  // 剪枝
}
```

**优先队列式：** 将队列改为大根堆（按ub排序），ub越大的越先出队。

**复杂度：** 最坏 O(2^n)

### 3.2 单源最短路径

**限界函数：** 路径长度更短则更新

```cpp
void bfs(int v) {
    NodeType e, e1;
    priority_queue<NodeType> pqu;  // 小根堆
    e.vno = v; e.length = 0;
    pqu.push(e); dist[v] = 0;
    while (!pqu.empty()) {
        e = pqu.top(); pqu.pop();
        for (j = 0; j < n; j++) {
            if (a[e.vno][j] < INF && e.length + a[e.vno][j] < dist[j]) {
                dist[j] = e.length + a[e.vno][j];
                prev[j] = e.vno;
                e1.vno = j; e1.length = dist[j];
                pqu.push(e1);
            }
        }
    }
}
```

### 3.3 任务分配问题

**限界函数（求下界）：**
```cpp
void bound(NodeType &e) {
    int minsum = 0;
    for (i1 = e.i+1; i1 <= n; i1++) {
        int minc = INF;
        for (j1 = 1; j1 <= n; j1++)
            if (!e.worker[j1] && c[i1][j1] < minc)
                minc = c[i1][j1];
        minsum += minc;
    }
    e.lb = e.cost + minsum;
}
```

**剪枝条件：** e.lb ≤ mincost 才入队

### 3.4 流水作业调度问题

**限界函数：**
```cpp
void bound(NodeType &e) {
    int sum = 0;
    for (i = 1; i <= n; i++)
        if (e.y[i] == 0) sum += b[i];
    e.lb = e.f2 + sum;
}
```

**计算f1和f2：**
```
f1 = f1 + a[j]
f2 = max(f2, f1) + b[j]
```

**剪枝条件：** e.lb < bestf 才入队

## 四、分枝限界法求解步骤总结

1. 确定限界函数（上界/下界）
2. 选择活结点表组织方式（队列/优先队列）
3. 设计剪枝条件
4. 设计解向量保存方式
5. BFS搜索直到找到最优解

---

## 五、易错点总结

1. **限界函数方向**：求最大值用上界(ub)，求最小值用下界(lb)
2. **剪枝条件**：ub > maxv（求最大）或 lb < bestf（求最小）才入队
3. **优先队列排序**：求最大值用大根堆，求最小值用小根堆
4. **解向量保存**：每个结点需要复制解向量，不能共享
5. **叶子结点处理**：到达叶子时比较更新最优解，不一定入队
