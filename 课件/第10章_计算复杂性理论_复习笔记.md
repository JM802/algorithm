# 第10章 计算复杂性理论期末复习笔记

## 一、章节概述

计算复杂性理论研究问题的本质难度，将问题分为P、NP、NPC等类别，是理解算法设计极限的理论基础。

---

## 二、核心概念

### 2.1 三类问题

| 类别 | 特征 | 示例 |
|------|------|------|
| **存在多项式算法** | 易解问题 | 排序、搜索 |
| **肯定不存在多项式算法** | 难解问题 | 停机问题 |
| **尚未确定** | NPC问题 | 旅行商、团问题 |

### 2.2 P问题（Polynomial Problem）

**定义：** 能用**确定性算法**在**多项式时间**内求解的**判定问题**。

```
P = {L | 存在确定性算法在O(n^k)时间内判定L}
```

**特点：**
- 确定性算法：每步只有一个选择
- 多项式时间：O(n^k)，k为常数
- 判定问题：答案为Yes/No

**示例：** 排序、最短路径、最小生成树

### 2.3 NP问题（Non-deterministic Polynomial Problem）

**定义：** 可以用**不确定性算法**在多项式时间内求解的判定问题。

**不确定性算法的两个阶段：**
1. **猜测阶段：** 非确定性地猜测一个解
2. **验证阶段：** 在多项式时间内验证该解的正确性

```
NP = {L | 存在多项式时间验证算法，对L的每个Yes实例，存在一个证书可被验证}
```

**关键：** P ⊆ NP（P问题的解可以直接验证）

**示例：** 旅行商问题（验证一条路径是否为哈密顿回路可在多项式时间完成）

### 2.4 NPC问题（NP-Complete Problem）

**定义：** 问题D是NPC问题，需满足：
1. D ∈ NP
2. NP中**任何问题**都可在多项式时间内**归约**为D

```
NPC = {L | L ∈ NP 且 ∀L' ∈ NP, L' ≤p L}
```

**核心性质：**
- NPC问题是NP中最难的问题
- 若任一NPC问题存在多项式时间算法，则 **P = NP**
- 所有NPC问题在多项式时间可解性上等价

### 2.5 NP-hard问题

**定义：** 满足NPC条件(2)但不满足条件(1)的问题。

- 不一定属于NP类
- 至少与NPC问题一样难
- 示例：图灵停机问题

## 三、多项式时间归约（≤p）

### 3.1 归约的定义

问题A可多项式归约为问题B（A ≤p B），若：
1. A的每个实例x可通过函数f转化为B的实例f(x)
2. f可在多项式时间内计算
3. A(x) = B(f(x))

### 3.2 归约的性质

| 性质 | 含义 |
|------|------|
| **传递性** | A ≤p B，B ≤p C ⟹ A ≤p C |
| **易解性** | A ≤p B，B ∈ P ⟹ A ∈ P |
| **难解性** | A ≤p B，A ∉ P ⟹ B ∉ P |
| **NPC证明** | A ≤p B，A是NPC ⟹ B是NPC |

### 3.3 如何证明问题是NPC

**方法一（定义法）：**
1. 证明 L ∈ NP
2. 证明 ∀L' ∈ NP，L' ≤p L

**方法二（归约法）：**
1. 证明 L ∈ NP
2. 找一个已知NPC问题L'，证明 L' ≤p L

## 四、经典NPC问题归约链

```
电路SAT（第一个NPC问题）
  ↓ ≤p
SAT（布尔公式可满足性）
  ↓ ≤p
3-CNF-SAT
  ↓ ≤p
团问题（Clique）
  ↓ ≤p
顶点覆盖
  ↓ ≤p
哈密顿回路
  ↓ ≤p
旅行商问题（TSP）
  ↓ ≤p
子集和问题
```

### 4.1 电路SAT → SAT

每个逻辑电路可写成布尔公式，转换为多项式时间。

### 4.2 SAT → 3-CNF-SAT

三步转换：
1. 布尔公式 → 子句合取式（语法树 → 引入辅助变量）
2. 子句 → 合取范式（真值表法）
3. 子句 → 3文字合取式（引入辅助变量，每个子句至多变8个）

### 4.3 3-CNF-SAT → 团问题

**构造：**
- 每个子句对应一组3个顶点
- 不同组的顶点，若不互为否定则连边
- φ可满足 ⟺ 图中存在k团

### 4.4 团问题 → 顶点覆盖

**关系：** S是团 ⟺ V-S是顶点覆盖

### 4.5 顶点覆盖 → 哈密顿回路

**构造附件图（Widget）：**
- 每条边对应一个附件图（12个顶点）
- 选择器顶点对应顶点覆盖中的顶点
- 存在k顶点覆盖 ⟺ G'存在哈密顿回路

### 4.6 哈密顿回路 → TSP

将图G转化为完全图，边权为1（存在边）或2（不存在边）。

### 4.7 3-CNF-SAT → 子集和

构造集合S和目标值t，使3-CNF可满足 ⟺ S存在子集和为t。

## 五、P vs NP 问题

- **P = NP？** 是计算机科学最大的未解问题之一
- 若P = NP，则所有NP问题都有多项式时间算法
- 若P ≠ NP，则NPC问题没有多项式时间算法
- 大多数科学家认为 **P ≠ NP**

---

## 六、易错点总结

1. **NP不是"非多项式"**：NP = Nondeterministic Polynomial，是非确定性多项式
2. **NPC必须满足两个条件**：属于NP + 所有NP问题可归约到它
3. **归约方向**：A ≤p B 表示A"不比"B难，即A可转化为B
4. **NP-hard不一定在NP中**：NP-hard ≥ NPC
5. **第一个NPC问题**：电路可满足性（Cook 1971证明SAT是NPC）
