# 第9章 近似算法（Approximation Algorithm）期末复习笔记

## 一、章节概述

近似算法用于求解NP难问题的次优解，目标是在多项式时间内得到一个接近最优解的解，用**近似比**衡量解的质量。

---

## 二、核心概念

### 2.1 近似比（Approximation Ratio）

对于最小化问题，近似算法得到的解C满足：
```
C ≤ ρ · C*
```
其中C*是最优解，ρ为近似比（ρ ≥ 1）。

对于最大化问题：
```
C* ≤ ρ · C
```

### 2.2 近似模式

| 类型 | 定义 | 时间复杂度 |
|------|------|-----------|
| **多项式时间近似模式（PTAS）** | 对任意ε>0，近似比(1+ε) | n^f(1/ε) |
| **完全多项式时间近似模式（FPTAS）** | 近似比(1+ε) | (n/ε)^O(1) |

### 2.3 NPC问题的求解策略

1. 规模很小：用指数时间算法
2. 特殊情况：设计多项式时间算法
3. 一般情况：**近似算法**

## 三、经典近似算法

### 3.1 旅行商问题（TSP）近似算法

**问题：** 求带权无向图的最小费用哈密顿回路。

**近似算法（基于最小生成树）：**
```
1. 选择任一顶点v
2. 用Prim算法求最小生成树tree
3. 对tree进行DFS得到顶点序列path
4. 按path顺序组成哈密顿回路H
```

**代码实现：**
```cpp
void approxTSP(Graph g) {
    // (1) 选择任一顶点v
    // (2) Prim算法求最小生成树tree
    Prim(g, v, tree);
    // (3) DFS遍历tree得到path
    DFS(tree, v, path);
    // (4) 按path组成回路
    path.append(v);
    return path;
}
```

**时间复杂度：** O(n²)（Prim + DFS）

**注意：** 要求图满足**三角不等式** c(u,w) ≤ c(u,v) + c(v,w)

### 3.2 顶点覆盖问题近似算法

**问题：** 找最小顶点集S，使每条边至少有一个端点在S中。

**近似算法（2-近似）：**
```
1. 随机选择一条边(u,v)
2. 将u和v加入覆盖集S
3. 删除与u和v相连的所有边
4. 重复直到无边剩余
```

**近似比：2**（因为每条选中的边最多"浪费"一条最优解中的边）

### 3.3 子集和问题近似算法

**问题：** 在集合S中找子集，使和≤t且最大。

**精确算法：** O(2^n) 指数时间

**近似算法（FPTAS）：**
```
1. L0 = {0}
2. for i = 1 to n:
   Li = Merge-lists(Li-1, Li-1 + xi)
   Li = Trim(Li, ε/2n)  // 修剪相近元素
   Remove from Li every element > t
3. return 最大值Z*
```

**Trim操作：** 删除满足 y/(1+δ) ≤ z ≤ y 的y（保留z）

**近似比：**(1+ε)，时间复杂度：O(n/ε)

---

## 四、易错点总结

1. **近似比定义**：最小化问题 C ≤ ρ·C*，最大化问题 C* ≤ ρ·C
2. **TSP近似需要三角不等式**：否则近似比无界
3. **顶点覆盖近似比为2**：不是最优，但是有保证的近似
4. **FPTAS vs PTAS**：FPTAS时间关于1/ε也是多项式，PTAS不是
5. **近似算法不适用于所有NPC问题**：有些问题求近似解和最优解一样难
