# 第5章 贪心法（Greedy Algorithm）期末复习笔记

## 一、章节概述

贪心法在求解问题时总是做出**当前看来最好的选择**，不从整体最优考虑，仅追求局部最优。需要证明贪心选择能导致全局最优。

---

## 二、核心概念

### 2.1 什么是贪心法

- 从某个初始解出发，逐步构造最优解
- 每一步根据**贪心准则（最优量度标准）**做出选择
- 每次贪心选择将问题简化为规模更小的子问题
- 期望通过局部最优选择产生全局最优解

### 2.2 贪心法适用的两个性质

| 性质 | 含义 |
|------|------|
| **贪心选择性质** | 整体最优解可通过一系列局部最优选择达到 |
| **最优子结构性质** | 最优解包含子问题的最优解 |

### 2.3 贪心法的一般求解过程

```cpp
SolutionType Greedy(SType a[], int n) {
    SolutionType x = {};        // 初始解向量为空
    for (int i = 0; i < n; i++) {
        SType xi = Select(a);   // 选择当前最好的分量
        if (Feasible(xi))       // 判断是否可行
            x = Union(x, xi);   // 合并到解中
    }
    return x;
}
```

### 2.4 贪心法与动态规划的比较

| 特征 | 贪心法 | 动态规划 |
|------|--------|----------|
| 决策方式 | 每步不可回溯 | 考虑所有可能的子问题 |
| 子问题 | 不寻找子问题最优解 | 寻找子问题最优解 |
| 效率 | 通常更高 | 通常较低 |
| 适用性 | 需要证明贪心选择性质 | 需要最优子结构+重叠子问题 |

## 三、经典贪心问题详解

### 3.1 活动安排问题

**问题：** n个活动，每个有开始时间和结束时间，资源同一时刻只能被一个活动占用，求最多能安排多少个兼容活动。

**贪心策略：** 按**结束时间递增排序**，每次选择结束时间最早且与已选活动兼容的活动。

**代码实现：**
```cpp
void solve() {
    memset(flag, 0, sizeof(flag));
    sort(A+1, A+n+1);          // 按结束时间递增排序
    int preend = 0;             // 前一个兼容活动的结束时间
    for (int i = 1; i <= n; i++) {
        if (A[i].b >= preend) { // 找到兼容活动
            flag[i] = true;
            preend = A[i].e;
            Count++;
        }
    }
}
```
**时间复杂度：O(nlog2n)**

**证明思路：**
1. 证明总存在一个以活动1（结束最早）开始的最优解
2. 做出贪心选择后，剩余问题与原问题形式相同（最优子结构）

### 3.2 分数背包问题

**问题：** n个物品，每个可取一部分（分数），背包容量W，求最大价值。

**贪心策略：** 按**单位重量价值（v/w）递减排序**，依次装入。

**代码实现：**
```cpp
void Knap() {
    V = 0;
    double weight = W;
    memset(x, 0, sizeof(x));
    int i = 1;
    while (A[i].w < weight) {   // 物品能全部装入
        x[i] = 1;
        weight -= A[i].w;
        V += A[i].v;
        i++;
    }
    if (weight > 0) {           // 部分装入
        x[i] = weight / A[i].w;
        V += x[i] * A[i].v;
    }
}
```
**时间复杂度：O(nlog2n)**

**注意：** 0/1背包不能用贪心法保证最优！

### 3.3 最小生成树（Prim算法）

**问题：** 求连通图的最小生成树。

**Prim贪心策略：** 每次选择连接已选顶点集U和未选顶点集V-U的**最小权边**。

**算法步骤：**
1. 初始化 U={v}（任选起点）
2. 重复n-1次：从候选边中选最小边，将V-U中顶点加入U
3. 更新候选边

**证明：** 用反证法，若最小生成树不含当前最小边，添加后形成回路，替换可得更小权值和，矛盾。

### 3.4 多机调度问题（MPS）

**问题：** n个作业，m台机器，求最短完成时间。

**贪心策略：** **最长处理时间作业优先（LPT）**，将处理时间最长的作业分配给最先空闲的机器。

**代码实现：**
```cpp
void solve() {
    if (n <= m) { /* 每台机器分配一个作业 */ return; }
    sort(A, A+n);              // 按处理时间递减排序
    priority_queue<NodeType> qu; // 小根堆
    for (int i = 0; i < m; i++) { // 先分配m个作业
        A[i].mno = i+1;
        qu.push(A[i]);
    }
    for (int j = m; j < n; j++) { // 分配余下作业
        e = qu.top(); qu.pop();   // 取最早空闲机器
        e.t += A[j].t;
        qu.push(e);
    }
}
```
**时间复杂度：O(nlog2n)**
**近似比：1.5 - 1/m**

### 3.5 哈夫曼编码

**问题：** 给定字符集及频率，构造最优不等长0/1编码。

**哈夫曼树构造：**
1. 将n个权值构造n棵单结点二叉树，得到集合F
2. 在F中选权值最小和次小的两棵树，合并为新二叉树
3. 重复直到F中只剩一棵树

**代码实现（用优先队列）：**
```cpp
void CreateHTree() {
    priority_queue<NodeType> qu;
    for (int i = 0; i < n; i++) qu.push(ht[i]);
    for (int j = n; j < 2*n-1; j++) {
        e1 = qu.top(); qu.pop();  // 权值最小
        e2 = qu.top(); qu.pop();  // 权值次小
        ht[j].weight = e1.weight + e2.weight;
        ht[j].lchild = e1.no;
        ht[j].rchild = e2.no;
        ht[e1.no].parent = ht[e2.no].parent = j;
        qu.push(ht[j]);
    }
}
```
**时间复杂度：O(nlog2n)**

**编码：** 从叶子到根，左0右1。

**证明：**
- 命题1：两个最小权值字符必须是最深的兄弟结点（贪心选择性质）
- 命题2：合并后的子问题仍具有最优子结构性质

### 3.6 流水作业调度问题（Johnson算法）

**问题：** n个作业在M1和M2上加工（先M1后M2），求最优加工顺序使总时间最短。

**Johnson贪心策略：**
1. 将作业按 a[i]≤b[i]（第1组N1）和 a[i]>b[i]（第0组N2）分组
2. N1按 a[i] 递增排序
3. N2按 b[i] 递减排序
4. 先执行N1的作业（顺序），再执行N2的作业（反序）

**代码实现：**
```cpp
int solve() {
    NodeType c[N];
    for (i = 0; i < n; i++) {
        c[i].no = i;
        c[i].group = (a[i] <= b[i]);
        c[i].time = a[i] <= b[i] ? a[i] : b[i];
    }
    sort(c, c+n);
    j = 0; k = n-1;
    for (i = 0; i < n; i++)
        if (c[i].group == 1) best[j++] = c[i].no;
        else best[k--] = c[i].no;
    // 计算总时间
    int f1 = 0, f2 = 0;
    for (i = 0; i < n; i++) {
        f1 += a[best[i]];
        f2 = max(f2, f1) + b[best[i]];
    }
    return f2;
}
```
**时间复杂度：O(nlog2n)**

### 3.7 带惩罚的任务调度

**贪心策略：** 按惩罚递减排序，若任务截止时间>已用时间则执行。

## 四、易错点总结

1. **贪心≠最优**：只有满足贪心选择性质和最优子结构时才能保证最优
2. **0/1背包不能用贪心**：分数背包可以，0/1背包需要用DP
3. **排序是关键**：大多数贪心问题第一步是排序，排序依据决定算法正确性
4. **活动安排 vs 会议安排**：前者贪心选最多活动数，后者DP选最大总时间
5. **Johnson算法分组**：N1按a升序，N2按b降序，顺序不能反
