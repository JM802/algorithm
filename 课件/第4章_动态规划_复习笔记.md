# 第4章 动态规划（Dynamic Programming）期末复习笔记

## 一、章节概述

动态规划是一种解决**多阶段决策问题**的优化方法，由 Richard Bellman 于1955年提出。核心思想是将复杂问题分解为一系列子问题，通过记录子问题的解避免重复计算，从而高效求解。

---

## 二、核心概念

### 2.1 动态规划的基本思想

- 将待求解问题分解为若干个**子问题（阶段）**，按顺序求解
- 前一子问题的解为后一子问题提供有用信息
- 在求解每个子问题时，列出各种可能的局部解，通过决策保留有可能达到最优的局部解
- 最后一个子问题的解就是初始问题的解

### 2.2 从斐波那契数列看DP

**递归算法的问题：**
```cpp
int Fib(int n) {
    if (n == 1 || n == 2) return 1;
    else return Fib(n-1) + Fib(n-2);
}
```
- 自顶向下执行，存在大量**重复计算**
- 例如 Fib(5) 的计算过程中，Fib(3) 被重复计算了2次

**DP改进：**
```cpp
int dp[MAX];
int Fib1(int n) {
    dp[1] = dp[2] = 1;
    for (int i = 3; i <= n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    return dp[n];
}
```
- 自底向上，每个子问题只计算一次
- 相同子问题只需查表，避免重复计算

### 2.3 DP适用的三个条件

| 条件 | 含义 |
|------|------|
| **最优子结构** | 问题的最优解包含子问题的最优解 |
| **无后效性** | 某阶段状态确定后，不受后续决策影响 |
| **重叠子问题** | 子问题之间不独立，可能被多次使用 |

### 2.4 DP求解步骤

1. 分析最优子结构性质，刻画其结构特征
2. 递归定义最优解（**状态转移方程**）
3. 以自底向上（bottom-up）或自顶向下记忆化（top-down with memoization）方式计算最优值
4. 根据计算最优值时得到的信息，构造问题的最优解

### 2.5 DP与分治法、贪心法的比较

| 方法 | 特点 |
|------|------|
| **分治法** | 子问题独立，无重叠 |
| **动态规划** | 子问题重叠，需记录子问题解 |
| **贪心法** | 每步做出不可回溯的局部最优选择 |

## 三、经典DP问题详解

### 3.1 整数拆分问题

**问题：** 求将正整数n无序拆分成最大数为k的拆分方案个数。

**状态转移方程：**
```
f(n,k) = 1                          当n=1或k=1
f(n,k) = f(n,n)                     当n<k
f(n,k) = f(n,n-1)+1                 当n=k
f(n,k) = f(n-k,k) + f(n,k-1)       其他情况
```

**代码实现（bottom-up）：**
```cpp
int dp[MAXN][MAXN];
void Split(int n, int k) {
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= k; j++) {
            if (i == 1 || j == 1)
                dp[i][j] = 1;
            else if (i < j)
                dp[i][j] = dp[i][i];
            else if (i == j)
                dp[i][j] = dp[i][j-1] + 1;
            else
                dp[i][j] = dp[i][j-1] + dp[i-j][j];
        }
}
```

**备忘录方法（top-down with memoization）：**
```cpp
int dp[MAXN][MAXN];
int dpf(int n, int k) {
    if (dp[n][k] != 0) return dp[n][k];
    if (n == 1 || k == 1) { dp[n][k] = 1; return dp[n][k]; }
    else if (n < k) { dp[n][k] = dpf(n, n); return dp[n][k]; }
    else if (n == k) { dp[n][k] = dpf(n, k-1) + 1; return dp[n][k]; }
    else { dp[n][k] = dpf(n, k-1) + dpf(n-k, k); return dp[n][k]; }
}
```

### 3.2 最大连续子序列和

**问题：** 给定n个整数的序列，求最大连续子序列的和。

**状态转移方程：**
```
dp[0] = 0
dp[j] = MAX{dp[j-1] + a[j], a[j]}    1≤j≤n
```
- 当 dp[j-1] > 0 时，dp[j] = dp[j-1] + a[j]
- 当 dp[j-1] ≤ 0 时，dp[j] = a[j]（放弃前面，从a[j]重新开始）

**代码实现：**
```cpp
void maxSubSum() {
    dp[0] = 0;
    for (int j = 1; j <= n; j++)
        dp[j] = max(dp[j-1] + a[j], a[j]);
}
```
**时间复杂度：O(n)**

### 3.3 最长公共子序列（LCS）

**问题：** 求两个序列的最长公共子序列。

**状态定义：** dp[i][j] 为子序列 a[0..i-1] 和 b[0..j-1] 的LCS长度。

**状态转移方程：**
```
dp[i][j] = 0                              i=0 或 j=0（边界）
dp[i][j] = dp[i-1][j-1] + 1              a[i-1] = b[j-1]
dp[i][j] = MAX(dp[i][j-1], dp[i-1][j])   a[i-1] ≠ b[j-1]
```

**构造LCS：**
从 dp[m][n] 开始回溯：
- 若 dp[i][j] == dp[i-1][j]，则 i--
- 若 dp[i][j] == dp[i][j-1]，则 j--
- 否则 a[i-1] 属于LCS，i--，j--

**代码实现：**
```cpp
void LCSlength() {
    for (i = 0; i <= m; i++) dp[i][0] = 0;
    for (j = 0; j <= n; j++) dp[0][j] = 0;
    for (i = 1; i <= m; i++)
        for (j = 1; j <= n; j++)
            if (a[i-1] == b[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i][j-1], dp[i-1][j]);
}
```
**时间复杂度：O(m×n)，空间复杂度：O(m×n)**

### 3.4 0/1背包问题

**问题：** n个物品，重量{w1..wn}，价值{v1..vn}，背包容量W，每个物品只能选或不选。

**状态转移方程：**
```
dp[i][0] = 0, dp[0][r] = 0           （边界条件）
dp[i][r] = dp[i-1][r]                当r < w[i]
dp[i][r] = MAX{dp[i-1][r], dp[i-1][r-w[i]]+v[i]}  其他
```

**回推最优解：**
从 dp[n][W] 开始，若 dp[i][r] ≠ dp[i-1][r]，则 x[i]=1，r=r-w[i]；否则 x[i]=0。

**代码实现：**
```cpp
void Knap() {
    for (i = 0; i <= n; i++) dp[i][0] = 0;
    for (r = 0; r <= W; r++) dp[0][r] = 0;
    for (i = 1; i <= n; i++)
        for (r = 1; r <= W; r++)
            if (r < w[i])
                dp[i][r] = dp[i-1][r];
            else
                dp[i][r] = max(dp[i-1][r], dp[i-1][r-w[i]]+v[i]);
}
```
**时间复杂度：O(n×W)，空间复杂度：O(n×W)**
**空间优化：** 可用一维数组，逆序遍历r

**注意：** 这是**伪多项式时间算法**（Pseudo Polynomial-time），因为W的值影响复杂度。

### 3.5 完全背包问题

**与0/1背包的区别：** 每种物品可以选任意多件。

**状态转移方程（优化后）：**
```
dp[i][j] = dp[i-1][j]                    当j < w[i]
dp[i][j] = MAX(dp[i-1][j], dp[i][j-w[i]]+v[i])  其他
```

**代码实现：**
```cpp
int solve1() {
    for (i = 1; i <= n; i++)
        for (j = 0; j <= W; j++)
            if (j < w[i])
                dp[i][j] = dp[i-1][j];
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]]+v[i]);
    return dp[n][W];
}
```
**时间复杂度：O(nW)**

### 3.6 资源分配问题

**问题：** 将资源（如员工）分配给多个使用者，使总收益最大。

**状态转移方程：**
```
dp[m+1][j] = 0                          （边界条件）
dp[i][s] = max(v[i][j] + dp[i+1][s-j])  0≤j≤s
```

### 3.7 会议安排问题（贪心+DP）

**问题：** 选择不重叠的订单，使总活动时间最长。

**方法：** 先按结束时间排序，再用DP：
```
dp[0] = A[0].length
dp[i] = max{dp[i-1], dp[j]+A[i].length}  （j为结束时间早于A[i].b的最晚订单）
```
**时间复杂度：O(nlog2n)**（二分查找）

## 四、DP解题模板

```cpp
// 1. 定义状态（dp数组的含义）
// 2. 写出状态转移方程
// 3. 确定边界条件
// 4. 确定遍历顺序
// 5. 推导验证

// 通用框架
int dp[N][M];  // 根据问题定义维度
// 初始化边界
for (i = 0; i <= n; i++)
    for (j = 0; j <= m; j++)
        dp[i][j] = 根据转移方程计算;
```

## 五、易错点总结

1. **状态定义不清**：dp[i][j]的含义必须明确，是"前i个"还是"第i个"
2. **边界条件遗漏**：dp[0][j]和dp[i][0]需要单独处理
3. **遍历顺序错误**：bottom-up需要先计算子问题；0/1背包空间优化时需要逆序遍历
4. **混淆0/1背包和完全背包**：完全背包用dp[i][j-w[i]]而非dp[i-1][j-w[i]]
5. **回推解时出错**：需要从dp[n][W]逆推，判断条件是dp[i][r]是否等于dp[i-1][r]
