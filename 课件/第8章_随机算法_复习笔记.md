# 第8章 随机算法（Randomized Algorithm）期末复习笔记

## 一、章节概述

随机算法允许在执行过程中随机选择下一步计算步骤，通常比确定性算法更简单、更快，但有一定概率产生错误结果。

---

## 二、核心概念

### 2.1 随机算法的特点

**优点：**
- 通常简单、易于实现
- 运算很快
- 很大概率得到最优结果

**缺点：**
- 有一定概率产生错误结果
- 较难计算时间复杂度和错误概率
- 很难得到真正完全随机数

### 2.2 四种随机算法类型

| 类型 | 特征 | 正确性 |
|------|------|--------|
| **数值随机算法** | 得到近似解，精度随时间提高 | 近似 |
| **蒙特卡罗（Monte Carlo）** | 可能得到错误解 | 概率正确 |
| **拉斯维加斯（Las Vegas）** | 找到的解一定正确，但可能找不到 | 解正确但可能无解 |
| **舍伍德（Sherwood）** | 总能得到正确解 | 总是正确 |

### 2.3 随机数发生器

**线性同余法：**
```
a0 = d  （随机种子）
an = (b * an-1 + c) mod m
```

**产生[a,b]随机整数：**
```cpp
int randa(int a, int b) {
    return rand() % (b - a + 1) + a;
}
```

### 2.4 期望时间

- **平均期望时间**：所有输入实例上平均的期望执行时间
- **最坏期望时间**：最坏输入实例上的期望执行时间

## 三、经典随机算法详解

### 3.1 数值随机算法——求定积分

**思想：** 随机投点法

```cpp
double solve() {
    int n = 10000;
    int m = 0;
    for (int i = 1; i <= n; i++) {
        double x = rand01();  // [0,1]随机数
        double y = rand01();
        if (x * x + y * y <= 1.0)
            m++;
    }
    return 4.0 * m / n;  // π ≈ 4m/n
}
```

**原理：** 圆面积/正方形面积 = π/4 ≈ m/n

### 3.2 蒙特卡罗算法——最小割问题

**问题：** 求多重图的最小割。

**算法：**
```
H = G
while |H(V)| > 2:
    随机选择一条边(x, y)
    收缩边(x, y)
Cut = 连接H中两个节点在G中的所有边
```

**正确性证明：**
- 引理：若最小割|C|=k，则|E|≥kn/2
- 第i步不选中C中边的概率 ≥ (n-i-1)/(n-i+1)
- 最终正确概率 > 2/n²
- 重复运行n²/2次，错误概率 < (1-2/n²)^(n²/2) ≈ 1/e

**时间复杂度：O(n²)**

### 3.3 拉斯维加斯算法——n皇后问题

**思想：** 随机放置皇后，冲突则重试，超时则返回失败。

```cpp
bool queen(int i, int n) {
    if (i > n) { dispasolution(n); return true; }
    int count = 0;
    while (count <= n) {
        int j = randa(1, n);  // 随机选择列
        count++;
        if (place(i, j)) break;
    }
    if (count > n) return false;
    q[i] = j;
    return queen(i+1, n);
}
```

**特点：**
- 找到的解一定正确
- 可能找到不到解
- 需要多次运行直到成功

### 3.4 舍伍德算法——随机快速排序

**问题：** 确定性快速排序在最坏情况下为O(n²)。

**改进：** 在划分前随机选择基准元素。

```cpp
void QuickSort(int a[], int s, int t) {
    if (s < t) {
        int j = randa(s, t);     // 随机选择基准
        swap(a[j], a[s]);        // 与第一个元素交换
        int i = Partition(a, s, t);
        QuickSort(a, s, i-1);
        QuickSort(a, i+1, t);
    }
}
```

**效果：**
- 消除最坏情况与输入实例的关联
- 最坏期望时间趋近 O(nlog2n)
- 平均时间复杂度没有改进，但计算时间对所有实例相对均匀

## 四、四种算法类型对比

| 类型 | 解的正确性 | 运行时间 | 适用场景 |
|------|-----------|---------|---------|
| 数值随机 | 近似解 | 确定 | 数值计算 |
| 蒙特卡罗 | 概率正确 | 确定 | 求精确解困难的问题 |
| 拉斯维加斯 | 解正确 | 随机 | 可能无解的问题 |
| 舍伍德 | 总是正确 | 随机 | 消除输入依赖 |

---

## 五、易错点总结

1. **蒙特卡罗 vs 拉斯维加斯**：前者可能错但总有结果，后者结果对但可能无结果
2. **随机种子**：srand(time(NULL)) 每次运行产生不同序列
3. **舍伍德算法不改进平均复杂度**：只是消除最坏情况
4. **最小割正确概率**：单次 > 2/n²，重复n²/2次后错误概率 < 1/e
5. **n皇后拉斯维加斯**：可能需要多次运行才能找到解
