## 二、递归的基本概念

### 2.1 递归的定义

**从定义角度看：** 在定义一个过程或函数时出现调用本过程或本函数的成分，称之为递归。

**从求解角度看：** 问题可以分解成一个或多个子问题，而这些子问题的结构以及求解方法与原问题是一样的，则可以采用递归技术求解问题。

### 2.2 递归的分类

| 分类 | 定义 | 示例 |
|------|------|------|
| **直接递归** | 过程或函数直接调用自身 | 求n! |
| **间接递归** | p调用q，q又调用p | — |
| **尾递归** | 递归调用是最后一条执行语句 | 求n!的递归实现 |
| **无重叠子问题递归** | 多次递归调用，但无重复 | 归并排序 |
| **有重叠子问题递归** | 多次递归调用，且有冗余递归调用 | 斐波那契数列 |

**按递归方向分类：**
- **线性递归（Linear Recursion）**：每次递归调用产生一个子问题
- **二叉递归（Binary Recursion）**：每次递归调用产生两个子问题
- **多路递归（Multi-way Recursion）**：每次递归调用产生多个子问题

### 2.3 使用递归的条件

能够用递归解决的问题应该满足以下三个条件：

1. 需要解决的问题可以转化为一个或多个子问题来求解，而这些子问题的求解方法与原问题完全相同，只是在数量规模上不同
2. 递归调用的次数必须是有限的
3. 必须有结束递归的条件来终止递归

### 2.4 何时使用递归

1. **定义是递归的**：如求n!和Fibonacci数列等
2. **数据结构是递归的**：如单链表、二叉树等
3. **问题的求解方法是递归的**：如汉诺塔问题

## 三、递归模型

### 3.1 递归模型的组成

一个递归模型由**递归出口**和**递归体**两部分组成：

- **递归出口**：确定递归到何时结束
- **递归体**：确定递归求解时的递推关系

**示例：求n!**

```
f(1) = 1                    （递归出口）
f(n) = n × f(n-1)     n>1   （递归体）
```

### 3.2 递归算法的执行过程

- 递归调用是函数嵌套调用的一种特殊情况，即调用自身代码
- 可以把每一次递归调用理解成调用自身代码的一个复制件
- 每次调用时，它的参量和局部变量均不相同，保证了各个复制件执行时的独立性
- 随着调用的不断深入，必定会出现调用到某一层的函数时，不再执行递归调用而终止函数的执行

## 四、递归与数学归纳法

### 4.1 第一数学归纳法原理

若{P(1)，P(2)，P(3)，P(4)，...}是命题序列且满足以下两个性质，则所有命题均为真：

1. P(1)为真
2. 任何命题均可以从它的前一个命题推导得出

**示例：证明 1+2+...+n = n(n+1)/2**

- 当n=1时，左式=1，右式=1×2/2=1，等式成立
- 假设当n=k-1时等式成立：1+2+...+(k-1) = (k-1)k/2
- 当n=k时，左式=1+2+...+k = 1+2+...+(k-1)+k = (k-1)k/2 + k = k(k+1)/2
- 等式成立

### 4.2 第二数学归纳法原理

若{P(1)，P(2)，P(3)，P(4)，...}是命题序列且满足以下两个性质，则对于其他自然数，该命题序列均为真：

1. P(1)为真
2. 任何命题均可以从它的前面所有命题推导得出

**示例：证明任何含有n（n≥0）个不同结点的二叉树，都可由它的中序序列和先序序列唯一地确定**

- 当n=0时，二叉树为空，结论正确
- 假设结点数小于n的任何二叉树都可以由其先序序列和中序序列唯一地确定
- 对于n个结点的二叉树，先序序列第一个元素a0为根结点，在中序序列中找到b[k]=a0，则左子树由a1...ak和b0...bk-1确定，右子树由ak+1...an-1和bk+1...bn-1确定

### 4.3 递归与归纳法的关系

- 数学归纳法是一种论证方法，而递归是算法和程序设计的一种实现技术
- 数学归纳法是递归的基础

## 五、递归算法设计的一般步骤

### 5.1 设计步骤

1. **对原问题f(sn)进行分析**，抽象出合理的"小问题"f(sn-1)
2. **假设f(sn-1)是可解的**，在此基础上确定f(sn)的解，即给出f(sn)与f(sn-1)之间的关系
3. **确定一个特定情况**（如f(1)或f(0)）的解，由此作为递归出口

### 5.2 示例：求整数数组的最大元素

**分析：**
- 设f(a，i)求解数组a中前i个元素即a[0..i-1]中的最大元素（大问题）
- f(a，i-1)求解数组a中前i-1个元素即a[0..i-2]中的最大元素（小问题）
- f(a，i) = MAX{f(a，i-1)，a[i-1]}
- f(a，1) = a[0]（递归出口）

**递归模型：**
```
f(a，i) = a[0]                     当i=1时
f(a，i) = MAX{f(a，i-1)，a[i-1]}  当i>1时
```

**代码实现：**
```cpp
int fmax(int a[], int i) {
    if (i == 1)
        return a[0];
    else
        return MAX(fmax(a, i-1), a[i-1]);
}
```

## 六、递归数据结构及其递归算法设计

### 6.1 递归数据结构的定义

采用递归方式定义的数据结构称为递归数据结构。在递归数据结构定义中包含的递归运算称为基本递归运算。

**形式化定义：** RD=(D, Op)
- D={di}（1≤i≤n，共n个元素）为构成该数据结构的所有元素的集合
- Op是基本递归运算的集合，具有封闭性

**示例：二叉树**
- D是给定二叉树及其子树的集合
- Op={op1, op2}
  - op1(p) = p->lchild
  - op2(p) = p->rchild

### 6.2 单链表的递归算法设计

**设计思路：**
- 设求解以L为首结点指针的整个单链表的某功能为"大问题"
- 求解除首结点外余下结点构成的单链表（由L->next标识）的相同功能为"小问题"
- 由大小问题之间的解关系得到递归体
- 考虑特殊情况（通常是单链表为空或者只有一个结点）得到递归出口

**示例：释放单链表所有结点**
```cpp
void DestroyList(LinkNode *&L) {
    if (L != NULL) {
        DestroyList(L->next);
        free(L);
    }
}
```

**示例：求单链表所有元素之和**
```cpp
int Sum(LinkList *L) {
    if (L == NULL)
        return 0;
    else
        return(L->data + Sum(L->next));
}
```

### 6.3 二叉树的递归算法设计

**设计思路：**
- 设求解以b为根结点的整个二叉树的某功能为"大问题"
- 求解其左、右子树的相同功能为"小问题"
- 由大小问题之间的解关系得到递归体
- 考虑特殊情况（通常是二叉树为空或者只有一个结点）得到递归出口

**示例：求二叉树所有结点值之和**
```cpp
int Sumbt(BTNode *bt) {
    if (bt->lchild == NULL && bt->rchild == NULL)
        return bt->data;  // 只有一个结点时返回该结点值
    else
        return Sumbt(bt->lchild) + Sumbt(bt->rchild) + bt->data;
}
```

**示例：由先序和中序序列创建二叉链**
```cpp
BTNode *CreateBTree(ElemType a[], ElemType b[], int n) {
    int k;
    if (n <= 0) return NULL;
    ElemType root = a[0];  // 根结点值
    BTNode *bt = (BTNode *)malloc(sizeof(BTNode));
    bt->data = root;
    for (k = 0; k < n; k++)  // 在b中查找b[k]=root的根结点
        if (b[k] == root)
            break;
    bt->lchild = CreateBTree(a+1, b, k);  // 递归创建左子树
    bt->rchild = CreateBTree(a+k+1, b+k+1, n-k-1);  // 递归创建右子树
    return bt;
}
```

**示例：输出从根结点到值为x的结点的路径**
```cpp
bool Findxpath(BTNode *bt, int x, vector<int> tmppath, vector<int> &path) {
    if (bt == NULL)  // 空树返回false
        return false;
    tmppath.push_back(bt->data);  // 当前结点加入path
    if (bt->data == x) {  // 当前结点值为x，返回true
        path = tmppath;  // 路径复制
        return true;
    }
    bool find = Findxpath(bt->lchild, x, tmppath, path);  // 在左子树中查找
    if (find)  // 左子树中成功找到
        return true;
    else  // 左子树中没有找到，在右子树中查找
        return Findxpath(bt->rchild, x, tmppath, path);
}
```

## 七、基于归纳思想的递归算法设计

### 7.1 示例：输出十进制数的各数字位

**分析：**
- 设n为m位十进制数am-1am-2...a1a0（m>0）
- n%10=a0，n/10=am-1am-2...a1
- 设f(n)的功能是输出十进制数n的各数字位（大问题）
- f(n/10)的功能是输出除a0外的各数字位（小问题）

**递归模型：**
```
f(n) ≡ 不做任何事件           当n=0时
f(n) ≡ f(n/10); 输出n%10     其他情况
```

**代码实现：**
```cpp
void digits(int n) {
    if (n != 0) {
        digits(n/10);
        printf("%d", n%10);
    }
}
```

### 7.2 示例：Distant Descendants

## 八、递归算法设计示例

### 8.1 简单选择排序

**分析：**
- 设f(a，n，i)用于对a[i..n-1]元素序列进行简单选择排序（大问题）
- f(a，n，i+1)用于对a[i+1..n-1]元素序列进行简单选择排序（小问题）
- 当i=n-1时所有元素有序，算法结束

**递归模型：**
```
f(a，n，i) ≡ 不做任何事情，算法结束           当i=n-1
f(a，n，i) ≡ 通过简单比较挑选a[i..n-1]中的最小元素a[k]放在a[i]处;
              否则f(a，n，i+1)
```

**代码实现：**
```cpp
void SelectSort(int a[], int n, int i) {
    int j, k;
    if (i == n-1) return;  // 满足递归出口条件
    else {
        k = i;  // k记录a[i..n-1]中最小元素的下标
        for (j = i+1; j < n; j++)  // 在a[i..n-1]中找最小元素
            if (a[j] < a[k])
                k = j;
        if (k != i)  // 若最小元素不是a[i]
            swap(a[i], a[k]);  // a[i]和a[k]交换
        SelectSort(a, n, i+1);
    }
}
```

**算法分析：** 比较次数f(n)=n(n-1)/2=O(n²)

### 8.2 冒泡排序

**分析：**
- 设f(a，n，i)用于对a[i..n-1]元素序列进行冒泡排序（大问题）
- f(a，n，i+1)用于对a[i+1..n-1]元素序列进行冒泡排序（小问题）
- 当i=n-1时所有元素有序，算法结束

**递归模型：**
```
f(a，n，i) ≡ 不做任何事情，算法结束           当i=n-1
f(a，n，i) ≡ 对a[i..n-1]元素序列，从a[n-1]开始进行相邻元素比较;
              若相邻两元素反序则将两者交换;
              若没有交换则返回，否则执行f(a，n，i+1);
```

**代码实现：**
```cpp
void BubbleSort(int a[], int n, int i) {
    int j;
    bool exchange;
    if (i == n-1) return;  // 满足递归出口条件
    else {
        exchange = false;  // 置exchange为false
        for (j = n-1; j > i; j--)
            if (a[j] < a[j-1]) {  // 当相邻元素反序时
                swap(a[j], a[j-1]);
                exchange = true;  // 发生交换置exchange为true
            }
        if (exchange == false)  // 未发生交换时直接返回
            return;
        else  // 发生交换时继续递归调用
            BubbleSort(a, n, i+1);
    }
}
```

### 8.3 n皇后问题

**问题描述：** 在n×n的方格棋盘上，放置n个皇后，要求每个皇后不同行、不同列、不同左右对角线。

**冲突判断：** 对于(i，j)位置上的皇后，是否与已放好的皇后(k，q[k])（1≤k≤i-1）有冲突？
```
(q[k] == j) || (abs(q[k] - j) == abs(i - k))
```
- q[k]==j 表示同列
- abs(q[k]-j)==abs(i-k) 表示在同一对角线上

**递归模型：**
```
queen(i，n) ≡ n个皇后放置完毕，输出一个解   若i>n
queen(i，n) ≡ 在第i行的合适的位置(i,j)在其上放置一个皇后;
              queen(i+1，n);               其他情况
```

**代码实现：**
```cpp
bool place(int i, int j) {  // 测试(i,j)位置能否摆放皇后
    if (i == 1) return true;  // 第一个皇后总是可以放置
    int k = 1;
    while (k < i) {  // k=1～i-1是已放置了皇后的行
        if ((q[k] == j) || (abs(q[k] - j) == abs(i - k)))
            return false;
        k++;
    }
    return true;
}

void queen(int i, int n) {  // 放置第i行的皇后
    if (i > n)
        dispasolution(n);  // 所有皇后放置结束
    else {
        for (int j = 1; j <= n; j++)  // 在第i行上试探每一个列j
            if (place(i, j)) {  // 在第i行上找到一个合适位置(i,j)
                q[i] = j;
                queen(i+1, n);
            }
    }
}
```

## 九、众数问题（The Majority Element）

### 9.1 问题描述

令A[1..n]是一个整数序列，A中的整数a如果在A中出现的次数多于⌊n/2⌋，那么a称为众数。

### 9.2 方法1：蛮力法

把每个元素和其他每个元素比较，并且对每个元素计数。如果某个元素的计数大于⌊n/2⌋，就可以断言它是多数元素。比较次数为O(n²)。

### 9.3 方法2：基于排序的方法

对这些元素排序，并且计算中间元素在序列中出现多少次。最坏情况下的代价为Θ(nlogn)。

### 9.4 方法3：归纳法（O(n)时间）

**观察结论：** 在原序列中去除两个不同的元素后，那么在原序列中的众数在新序列中还是众数。

**证明：**
- 假设n个元素的数组中有众数a，其频度m超过⌊n/2⌋
- 去掉两个元素，有两种情况：
  - 如果两个元素都不是a，那么a必然是剩余n-2个元素的众数
  - 如果两个元素一个是a，那么a必然是剩余n-2个元素的众数

**算法：**
1. 将计数器置1，并令c=A[1]
2. 从A[2]开始，逐个地扫描元素
3. 如果被扫描的元素和c相等，则计数器加1
4. 如果元素不等于c，则计数器减1
5. 如果计数器为0，那么对于A[j+1..n]上的元素递归调用candidate过程
6. 最后计算候选者c出现的次数，若大于n/2，即为所求

**时间复杂度：O(n)**

## 十、汉诺塔问题

**问题描述：** 设有3个塔座X、Y、Z，X塔座上有n个盘片，要求将n个盘片从X通过Y移动到Z上。

**规则：**
1. 每次只能移动一个盘片
2. 盘片可以插在X、Y和Z中任一塔座
3. 任何时候都不能将一个较大的盘片放在较小的盘片上

**递归分解：**
```
Hanoi(n, x, y, z)
  Hanoi(n-1, x, z, y)；  // 将n-1个盘片从x通过z移到y
  move(n, x, z)；         // 将第n个圆盘从x移到z
  Hanoi(n-1, y, x, z)    // 将n-1个盘片从y通过x移到z
```

**时间复杂度：T(n) = O(2^n)**

## 十一、易错点总结

1. **递归三要素**：递归出口、递归体（大小问题关系）、递归调用
2. **尾递归**：递归调用是最后一条执行语句，可优化为循环
3. **递归数据结构**：定义中包含递归运算，如单链表、二叉树
4. **数学归纳法是递归的基础**：设计递归算法时，先用归纳法分析问题结构
5. **递归算法设计步骤**：抽象小问题→确定大小问题关系→确定递归出口
6. **众数问题的O(n)算法**：基于归纳法的观察结论，去除两个不同元素不改变众数
7. **n皇后冲突判断**：同列q[k]==j，同对角线abs(q[k]-j)==abs(i-k)
