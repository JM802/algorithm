## 二、算法的基本概念

### 2.1 什么是算法

算法是求解问题的一系列计算步骤，将输入数据转换成输出结果。

**五大特征：**

| 特征 | 含义 |
|------|------|
| **有限性** | 必须在有限步骤内结束 |
| **确定性** | 每一步骤都有确切定义，无歧义 |
| **可行性** | 每一步都可以通过基本操作有限次完成 |
| **输入性** | 有零个或多个输入 |
| **输出性** | 有一个或多个输出 |

### 2.2 好算法的目标

- 正确性
- 可使用性
- 可读性
- 健壮性
- 高效率与低存储量需求

### 2.3 算法描述

用C/C++函数描述，返回值表示能否正确执行，引用型参数表示输出。

```cpp
bool fun(int n, int &s) {
    if (n < 0) return false;
    s = 0;
    for (int i = 1; i <= n; i++) s += i;
    return true;
}
```

## 三、算法分析

### 3.1 时间复杂度

**基本操作：** 固定时间完成的操作（算术运算、比较、分配空间等）

**频度：** 语句或运算的执行次数

**分析步骤：**
1. 确定问题规模n
2. 找出基本语句，求执行次数f(n)
3. 用O、Ω、Θ表示阶

### 3.2 渐进符号

| 符号 | 含义 | 用途 |
|------|------|------|
| **O（大O）** | 上界：f(n) ≤ c·g(n) | 最坏情况时间复杂度 |
| **Ω（大Ω）** | 下界：f(n) ≥ c·g(n) | 最好情况时间复杂度 |
| **Θ（大Θ）** | 紧确界：c1·g(n) ≤ f(n) ≤ c2·g(n) | 精确时间复杂度 |

**规则：** 多项式 f(n) = a_m·n^m + ... + a_1·n + a_0，则 f(n) = Θ(n^m)

### 3.3 最好、最坏和平均情况

- **最好情况 G(n)：** 所有输入中执行次数最少
- **最坏情况 W(n)：** 所有输入中执行次数最多
- **平均情况 A(n)：** 各输入下执行次数的加权平均

### 3.4 常见时间复杂度排序

```
O(1) < O(log2n) < O(n) < O(nlog2n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

## 四、经典算法分析示例

### 4.1 顺序查找

```cpp
int Find(double a[], int n, double x) {
    int i = 0;
    while (i < n) {
        if (a[i] == x) break;
        i++;
    }
    return (i < n) ? 1 : 0;
}
```

- 最好情况：O(1)（第一个元素就是x）
- 最坏情况：O(n)（最后一个元素是x或不存在）
- 平均情况：O(n)

### 4.2 二分查找

```cpp
int BinarySearch(int a[], int n, int x) {
    int low = 1, high = n, j = 0;
    while (low <= high && j == 0) {
        int mid = (low + high) / 2;
        if (x == a[mid]) j = mid;
        else if (x < a[mid]) high = mid - 1;
        else low = mid + 1;
    }
    return j;
}
```

**时间复杂度：O(log2n)**
**最大比较次数：⌊log2n⌋ + 1**

### 4.3 归并排序（递归分析）

```
T(n) = O(1)          当n=1
T(n) = 2T(n/2) + O(n)  当n>1
```

**解：T(n) = O(nlog2n)**

### 4.4 汉诺塔（递归分析）

```
T(n) = O(1)      当n=1
T(n) = 2T(n-1) + 1  当n>1
```

**解：T(n) = O(2^n)**

## 五、递推关系求解

### 5.1 特征方程法

对于 f(n) = a1·f(n-1) + a2·f(n-2)：
- 特征方程：x² - a1·x - a2 = 0
- 若根 r1 ≠ r2：f(n) = c1·r1^n + c2·r2^n
- 若根 r1 = r2 = r：f(n) = c1·r^n + c2·n·r^n

### 5.2 主方法（Master Method）

对于 T(n) = aT(n/b) + f(n)：

| 条件 | 结论 |
|------|------|
| f(n) = O(n^(log_b(a)-ε)) | T(n) = Θ(n^log_b(a)) |
| f(n) = Θ(n^log_b(a)) | T(n) = Θ(n^log_b(a) · logn) |
| f(n) = Ω(n^(log_b(a)+ε)) | T(n) = Θ(f(n)) |

## 六、空间复杂度

只考虑**临时变量**所占空间，不计形参。

```cpp
int max(int a[], int n) {
    int i, maxi = 0;  // 临时变量
    for (i = 1; i < n; i++)
        if (a[i] > a[maxi]) maxi = i;
    return a[maxi];
}
```
**空间复杂度：O(1)**

**递归算法空间复杂度：** 考虑递归栈深度

## 七、易错点总结

1. **O(1)不是执行1次**，是与n无关的常数时间
2. **Θ比O更精确**，Θ表示上下界同阶
3. **空间复杂度不计形参**，只计临时变量
4. **递归空间复杂度**要考虑递归栈深度
5. **主方法三种情况**：f(n)与n^log_b(a)比较，取多项式意义上的大小
