## 二、最小生成树（MST）

### 2.1 概念

- **生成树：** 连通图的极小连通子图，含全部n个顶点和n-1条边
- **最小生成树：** 所有生成树中边权之和最小的树

### 2.2 Prim算法

**思想：** 从一个顶点开始，每次添加连接已选集合U和未选集合V-U的最小权边。

**算法步骤：**
1. 初始化 U={v}
2. 重复n-1次：选U到V-U的最小权边，将V-U中顶点加入U

**辅助数组：**
- `lowcost[j]`：V-U中顶点j到U的最小边权
- `closest[j]`：该边在U中的端点

```cpp
void Prim(MGraph g, int v) {
    int lowcost[MAXV], closest[MAXV];
    for (j = 0; j < g.n; j++) {
        lowcost[j] = g.edges[v][j];
        closest[j] = v;
    }
    for (i = 1; i < g.n; i++) {
        mincost = INF;
        for (j = 0; j < g.n; j++)
            if (lowcost[j] != 0 && lowcost[j] < mincost) {
                mincost = lowcost[j]; k = j;
            }
        printf("边(%d,%d)权为:%d\n", closest[k], k, mincost);
        lowcost[k] = 0;
        for (j = 0; j < g.n; j++)
            if (g.edges[k][j] != 0 && g.edges[k][j] < lowcost[j]) {
                lowcost[j] = g.edges[k][j];
                closest[j] = k;
            }
    }
}
```

**时间复杂度：O(n²)**
**适用：稠密图**

### 2.3 Kruskal算法

**思想：** 按权值递增顺序选边，不形成回路则加入。

**关键：** 用**并查集**判断是否形成回路。

**并查集操作：**
- `MAKE_SET`：初始化，每个元素为独立集合
- `FIND_SET(x)`：查找x所属集合（路径压缩）
- `UNION(x,y)`：合并x和y所在集合（按秩合并）

```cpp
void Kruskal(MGraph g) {
    Edge E[MaxSize];
    UFSTree t[MaxSize];
    // 提取边集并排序
    sort(E, E+k);
    MAKE_SET(t, g.n);
    k = 1; j = 0;
    while (k < g.n) {
        u1 = E[j].u; v1 = E[j].v;
        sn1 = FIND_SET(t, u1);
        sn2 = FIND_SET(t, v1);
        if (sn1 != sn2) {
            printf("(%d,%d):%d\n", u1, v1, E[j].w);
            k++;
            UNION(t, u1, v1);
        }
        j++;
    }
}
```

**时间复杂度：O(elog2e)**
**适用：稀疏图**

### 2.4 Prim vs Kruskal

| 特征 | Prim | Kruskal |
|------|------|---------|
| 策略 | 顶点扩展 | 边排序 |
| 数据结构 | 数组 | 并查集 |
| 时间复杂度 | O(n²) | O(elog2e) |
| 适用场景 | 稠密图 | 稀疏图 |

## 三、最短路径

### 3.1 Dijkstra算法（单源最短路径）

**思想：** 贪心法，每次选距源点最近的未访问顶点，更新其邻居距离。

**辅助数组：**
- `dist[i]`：源点v到顶点i的当前最短距离
- `path[i]`：最短路径中i的前驱顶点
- `S[i]`：顶点i是否已加入集合S

```cpp
void Dijkstra(MGraph g, int v) {
    int dist[MAXV], path[MAXV], S[MAXV];
    for (i = 0; i < g.n; i++) {
        dist[i] = g.edges[v][i];
        S[i] = 0;
        path[i] = (g.edges[v][i] < INF) ? v : -1;
    }
    S[v] = 1; path[v] = 0;
    for (i = 0; i < g.n; i++) {
        mindis = INF;
        for (j = 0; j < g.n; j++)
            if (S[j] == 0 && dist[j] < mindis) {
                u = j; mindis = dist[j];
            }
        S[u] = 1;
        for (j = 0; j < g.n; j++)
            if (S[j] == 0 && dist[u] + g.edges[u][j] < dist[j]) {
                dist[j] = dist[u] + g.edges[u][j];
                path[j] = u;
            }
    }
}
```

**时间复杂度：O(n²)**
**限制：** 不能有负权边

### 3.2 Floyd算法（多源最短路径）

**思想：** 动态规划，逐步允许经过更多中间顶点。

**状态转移方程：**
```
A[-1][i][j] = g.edges[i][j]
A[k][i][j] = MIN(A[k-1][i][j], A[k-1][i][k] + A[k-1][k][j])
```

**时间复杂度：O(n³)**
**适用：稠密图，求所有顶点对之间的最短路径**

### 3.3 Bellman-Ford算法（单源最短路径，支持负权边）

**状态转移方程：**
```
dist[1][u] = g.edges[v][u]
dist[k][u] = MIN{dist[k-1][u], MIN{dist[k-1][i]+g.edges[i][u]}}
```

**时间复杂度：O(n³)**

## 四、旅行商问题（TSP）

### 4.1 概念

- 哈密顿回路：经过每个顶点恰好一次的回路
- TSP：求最小权哈密顿回路
- 是**NP完全问题**

### 4.2 精确算法（动态规划）

**状态转移方程（Held-Karp）：**
```
dp[S][i] = MIN{dp[S-{i}][j] + cost[j][i]}  j ∈ S, j ≠ i
```

**时间复杂度：O(2^n · n²)**
**空间复杂度：O(2^n · n)**

## 五、网络流

### 5.1 基本概念

- **容量网络：** 有向图G=(V,E)，每条边有容量c(u,v)
- **流：** 满足容量限制和流量守恒的函数f(u,v)
- **最大流：** 从源点s到汇点t的最大流量

### 5.2 Ford-Fulkerson方法

**核心思想：** 在残余网络中不断寻找增广路径

**关键概念：**
- **残余容量：** r(u,v) = c(u,v) - f(u,v)
- **增广路径：** 残余网络中从s到t的路径

### 5.3 最大流最小割定理

```
最大流 = 最小割
```

## 六、易错点总结

1. **Prim适合稠密图，Kruskal适合稀疏图**
2. **Dijkstra不能处理负权边**，Floyd和Bellman-Ford可以
3. **Floyd是DP思想**，三重循环顺序k-i-j
4. **并查集路径压缩**：FIND_SET时直接指向根结点
5. **MST不唯一**，但最小权值和唯一（边权互异时MST唯一）
6. **Dijkstra正确性前提**：无负权边，贪心选择安全
