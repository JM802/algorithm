# 第6章 回溯法（Backtracking Algorithm）期末复习笔记

## 一、章节概述

回溯法是一种在**解空间树**中按**深度优先搜索**策略寻找问题解的算法。核心思想是"走不通就退回再走"，通过剪枝函数避免无效搜索。

---

## 二、核心概念

### 2.1 问题的解空间

- 解空间由所有可能的决策序列组成
- 解向量 X={x1, x2, ..., xn}，分量xi表示第i步的操作
- 解空间用**树**形式组织（解空间树/状态空间树）

**解空间树的两种类型：**

| 类型 | 适用场景 | 结构 |
|------|---------|------|
| **子集树** | 从n个元素中选子集 | 每个结点有选/不选两个分支，共2^n个叶子 |
| **排列树** | 确定n个元素的排列 | 每层有n-i+1个分支，共n!个叶子 |

### 2.2 回溯法的基本思想

1. 从根结点出发，按**深度优先**策略搜索
2. 当前结点分为三种状态：
   - **活结点**：自身已生成但孩子未全部生成
   - **扩展结点**：正在产生孩子结点的结点
   - **死结点**：部分解不满足约束或子结点已搜索完毕
3. 无法向纵深移动时，**回溯**至最近的活结点
4. 直至找到解或无活结点为止

### 2.3 剪枝函数

| 函数类型 | 作用 |
|---------|------|
| **约束函数** | 在扩展结点处剪除不满足约束的子树 |
| **限界函数** | 剪去得不到最优解的子树 |

### 2.4 回溯法求解步骤

1. 确定问题的解空间树（至少包含一个最优解）
2. 确定结点的扩展搜索规则
3. 以深度优先方式搜索，用剪枝函数避免无效搜索

## 三、算法框架

### 3.1 非递归回溯框架

```cpp
int x[n];  // 解向量
void backtrack(int n) {
    int i = 1;
    while (i >= 1) {
        if (i > n) {
            // 处理一个完整解
            // ...
        }
        // 检查当前结点是否为扩展结点
        // 如果是，生成下一个子结点
        // 否则回溯
    }
}
```

### 3.2 递归回溯框架（子集树）

```cpp
void backtrack(int i) {
    if (i > n) {
        // 到达叶子结点，处理解
        输出解;
    } else {
        for (j = 0; j <= 1; j++) {  // 选或不选
            x[i] = j;
            if (约束函数和限界函数满足)
                backtrack(i+1);
        }
    }
}
```

### 3.3 递归回溯框架（排列树）

```cpp
void backtrack(int i) {
    if (i > n) {
        输出解;
    } else {
        for (j = i; j <= n; j++) {
            swap(x[i], x[j]);  // 交换产生新排列
            if (约束函数和限界函数满足)
                backtrack(i+1);
            swap(x[i], x[j]);  // 恢复（回溯）
        }
    }
}
```

## 四、经典回溯问题详解

### 4.1 0/1背包问题（回溯法）

**解空间：** 子集树，x[i]=0表示不选第i个物品，x[i]=1表示选。

**约束函数：** 装入重量不超过W
```cpp
cw + w[i] <= W
```

**限界函数：** 剩余物品价值上界 > 当前最优值
```cpp
cp + r[i] > bestp  // r[i]为剩余物品价值上界
```

**代码框架：**
```cpp
void backtrack(int i) {
    if (i > n) {
        if (cp > bestp) { bestp = cp; 保存最优解; }
        return;
    }
    // 左子树：选物品i
    if (cw + w[i] <= W) {
        cw += w[i]; cp += v[i];
        backtrack(i+1);
        cw -= w[i]; cp -= v[i];  // 回溯
    }
    // 右子树：不选物品i
    if (cp + r[i] > bestp)
        backtrack(i+1);
}
```

### 4.2 装载问题

**问题：** 两个集装箱，轮船载重W，求两船最大装载重量。

**解法：** 用回溯法求第一艘船的最大装载，剩余给第二艘。

### 4.3 子集和问题

**问题：** 给定正整数集合S和目标值t，求S中和为t的所有子集。

**解空间：** 子集树

**约束函数：**
- 左子树：cw + w[i] <= t
- 右子树：cw + r[i] >= t（剩余元素之和 >= 还需要的值）

### 4.4 n皇后问题

**问题：** 在n×n棋盘上放置n个皇后，使其互不攻击。

**解空间：** 排列树（每行放一个皇后，x[i]表示第i行皇后的列号）

**约束函数（判断是否合法）：**
```cpp
bool place(int i) {
    for (int j = 1; j < i; j++)
        if (x[i] == x[j] || abs(i-j) == abs(x[i]-x[j]))
            return false;  // 同列或同对角线
    return true;
}
```

**代码实现：**
```cpp
void backtrack(int t) {
    if (t > n) 输出解;
    else {
        for (int j = 1; j <= n; j++) {
            x[t] = j;
            if (place(t))
                backtrack(t+1);
        }
    }
}
```

### 4.5 任务分配问题

**问题：** n个人分配n项任务，第i个人做第j项任务的成本为c[i][j]，求最小总成本。

**解空间：** 排列树

**约束函数：** 每人分配不同任务

**限界函数：** 当前成本+剩余最小成本 < 当前最优值

### 4.6 活动安排问题（回溯法）

**解空间：** 子集树，x[i]=1表示选择活动i

**约束函数：** 新活动与已选活动兼容

### 4.7 流水作业调度问题（回溯法）

**解空间：** 排列树（作业的加工顺序排列）

**限界函数：** 计算当前排列的完成时间下界

## 五、回溯法效率分析

- 最坏时间复杂度：O(2^n)（子集树）或 O(n!)（排列树）
- 实际效率取决于剪枝函数的质量
- 剪枝越强，实际搜索的结点越少

---

## 六、回溯法 vs 动态规划 vs 贪心法

| 特征 | 回溯法 | 动态规划 | 贪心法 |
|------|--------|----------|--------|
| 搜索方式 | 深度优先+剪枝 | 自底向上填表 | 贪心选择 |
| 适用问题 | 找所有解/最优解 | 最优化问题 | 最优化问题 |
| 时间复杂度 | 指数级（最坏） | 多项式级 | 多项式级 |
| 保证最优 | 是 | 是 | 需证明 |
| 空间 | O(解空间深度) | O(子问题数) | O(1) |

## 七、易错点总结

1. **回溯必须恢复状态**：递归返回后要撤销之前的修改（如swap回来、cw/cp减回去）
2. **剪枝函数顺序**：先检查约束函数，再检查限界函数
3. **n皇后place函数**：要检查同行、同列、两条对角线
4. **子集树 vs 排列树**：子集树每个位置选或不选(2^n)；排列树是全排列(n!)
5. **限界函数设计**：需要计算当前解的上界/下界，与最优值比较
